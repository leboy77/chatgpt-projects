## 推荐使用

优先使用：

```text
01_推荐安装包/Temu商品首图采集器_v0.3.1.zip
```

安装方式：

1. 解压推荐安装包。
2. 打开 Chrome 或比特浏览器的扩展程序页。
3. 开启“开发者模式”。
4. 点击“加载未打包的扩展程序”。
5. 选择解压后的 `temu-image-collector` 目录。
6. 刷新 Temu 商品列表页。

## 当前源码

`04_当前源码/temu-image-collector` 是 v0.3.1 的完整可编辑源码，包括：

- Manifest V3 配置
- 商品发现与三种采集模式
- Quick look 色值/轮播读取
- File System Access 保存目录桥
- Service Worker 缓存清理
- JSZip 依赖与图标

运行所需的探测脚本和测试图片不在最终源码目录中。
