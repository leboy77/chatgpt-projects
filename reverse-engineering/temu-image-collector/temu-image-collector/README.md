# Temu 商品首图采集器

## 功能

- 简单采集：读取商品卡片当前首图。
- 多首图采集：打开 Quick look，获取每个色值的首图。
- 完整采集：获取每个色值的全部轮播图，并按商品和色值分文件夹。
- 详情图采集：从列表进入每个商品详情页，采集详情页当前所有色值的图片和完整标题；默认采集全部，可切换为“仅每色值首图”。
- 图片和 `商品标题.xlsx` 打包为一个 ZIP。
- 可切换“仅导出图片链接（TXT）”：不下载 JPG/PNG，采集完成后在预览窗口筛选，再把保留的纯图片链接写入文本。
- 自动翻页、翻页页数和本次目标商品数均可设置；达到目标立即停止，未达到则继续加载下一页。
- 图片模式在打包前显示小图预览；链接模式在导出前显示预览筛选窗口。
- 自动记录已采集图片链接，后续任务默认跳过重复链接；可在工具条清空记录。
- `过滤 AD` 使用“是/否”选项，默认“是”。

## 安装

1. 打开 Chrome/BitBrowser 的扩展程序页。
2. 开启“开发者模式”。
3. 选择“加载未打包的扩展程序”。
4. 选择解压后包含 `manifest.json` 的目录。
5. 刷新 Temu 商品列表页。

## 使用

1. 在商品卡片左上角点击“采集”。
2. 点击“全选可采集”可选中当前已加载的全部卡片。
3. 每排最右侧卡片右上角提供“本排全选 / 本排不选”按钮。点击“本排不选”可一次取消该视觉行内所有已选商品。
4. 在右下角工具条选择采集模式。
5. 选择“详情图采集”时，会显示“仅每色值首图”开关；默认关闭，即采集每个色值的全部详情图。
6. 可选：勾选“仅导出图片链接（TXT）”。开启后不会下载图片文件，而是直接生成链接文档。
7. 可选：勾选“采集商品标题”。开启后标题写入图片文件名和标题表；链接模式下不写商品 ID 或标题。
8. 可选：点击“选择保存目录”。授权后 ZIP 或 TXT 会直接写入该目录；未选择时使用浏览器默认下载目录。
9. 点击“开始采集”。
10. 采集完成后 ZIP 或 TXT 会写入所选目录或以默认下载方式保存。

### 自动翻页与数量限制

- “自动翻页”默认关闭。
- “页数”从当前页算作第 1 页，最大 100 页。
- “本次商品数”按商品卡片计数；填 `0` 表示不限制。
- 达到目标商品数后立即停止翻页；未达到则继续加载下一页，直到目标、页数上限或页面没有更多商品。
- 自动翻页时，若当前页已经手动勾选商品，则第 1 页按勾选结果采集；后续页采集全部可采集商品。
- 翻页通过 `See more / 查看更多 / 加载更多` 优先执行，不存在的会滚动加载，最后尝试下一页链接。

详情图采集会自动进入商品详情页，采集完成后自动进入下一个已选商品。页面跳转和 Temu 安全验证不会丢失任务，验证完成后可继续。

链接模式采集完成后会弹出图片预览窗口。点击某张图片的“删除”，该链接不会写入文档；可以点击“恢复”撤销删除，最后点击“确认导出”。文档每行只有一个图片 URL：

```text
https://img.kwcdn.com/product/example-goods.jpeg
```

该模式不生成 ZIP、`图片/` 或 `商品标题.xlsx`，只生成一个 `.txt` 文档。取消预览窗口则不生成文档。

图片模式也会在下载前显示“采集后图片小图预览”。确认后才生成 ZIP，取消则不打包。

### 重复链接与 AD

- “重复链接：跳过”默认开启。已经成功保存或导出的链接会写入本地记录，后续任务自动过滤。
- 预览中删除的链接不会记入历史，下次仍可再次采集。
- “清空链接记录”会清空本地历史，使所有链接可以重新采集。
- “过滤 AD：是”会跳过带 `AD` 标识的商品；选择“否”后，非推荐区的 AD 商品可以正常选择。推荐区仍会自动跳过。

“Top picks for you / 为你推荐”等推荐区以及带 `AD` 标识的广告商品会自动跳过，不注入采集按钮，也不会进入图片或 `商品标题.xlsx`。工具条摘要会显示已忽略数量。

采集过程中可点击“停止采集”。扩展会把当前已经下载成功或已经读取到的图片生成 ZIP，不会直接丢弃。若 Quick look 不存在，扩展会回退到卡片首图，并在工具条日志中显示警告。

批量采集时色值选项可能比轮播图更晚加载。v0.3.0 会等待并重新识别色值，不再依赖色值缩略图先加载完成；如果色值区域存在但仍无法识别，日志会显示对应商品 ID。尺码组会被明确排除，无法确认色值组时只保存默认图，不会按尺码重复采集。点击后未选中、标记为售罄或轮播图没有变化的色值会被跳过，不再复用上一色值的图片。

遇到 Temu 登录页或安全验证页时，扩展会暂停并保存任务进度，不生成半成品 ZIP。完成验证并返回 Temu 商品页后，点击“继续采集”即可恢复，已经完成的商品不会重复打开 Quick look。临时失败商品会在主批次结束后自动重试一次；仍失败的商品会保留，按钮变为“重试失败项”。

任务完成后的统计会分别显示：

- 已处理商品 / 已选商品
- 未处理商品
- 图片成功 / 失败
- 跳过色值
- 默认单色回退

工具条中的“清理 Temu 缓存”会清除当前 Temu 站点的 HTTP 缓存、Cache Storage 和 Service Worker，但不会清除 Cookie、账号或登录状态。清理后建议刷新页面。

工具条标题栏支持按住拖动，可放到页面任意可见区域并自动记住位置；双击标题栏可恢复右下角默认位置。窗口尺寸变化时，工具条会自动限制在可视范围内。

## 目录结构

下载的 ZIP 文件使用模式和本地时间命名。解压时由系统创建同名大文件夹，ZIP 内不再重复放置同名根目录：

```text
完整采集+2026-10-23_16-32-10.zip
└─ 完整采集+2026-10-23_16-32-10/
   ├─ 图片/
   └─ 商品标题.xlsx
```

ZIP 内只有 `图片/` 和 `商品标题.xlsx` 两个顶层项目。简单采集、多首图采集和完整采集的图片仍位于 `图片/` 内；完整采集继续按商品和色值分层：

```text
图片/{商品ID}_{商品标题}/{色值}/01.jpg
```

详情图采集不再创建商品、色值子文件夹，所有图片直接平铺在 `图片/`：

```text
图片/{商品ID}_{商品标题}_详情图_{色值}_{序号}.jpg
```

## 已知限制

- 扩展只处理页面已加载的商品卡片；新滚动加载的卡片需要重新点击“全选可采集”。
- Temu 页面结构和 Quick look 交互变化后，需要更新 DOM 选择器。
- 人工安全验证、登录验证和访问限制需要用户在浏览器中自行完成。
- 图片版权和平台使用规则由使用者自行确认。
