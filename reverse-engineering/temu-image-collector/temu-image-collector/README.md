# Temu 商品首图采集器

## 功能

- 简单采集：读取商品卡片当前首图。
- 多首图采集：打开 Quick look，获取每个色值的首图。
- 完整采集：获取每个色值的全部轮播图，并按商品和色值分文件夹。
- 全部图片与 `采集结果.json` 打包为一个 ZIP。

## 安装

1. 打开 Chrome/BitBrowser 的扩展程序页。
2. 开启“开发者模式”。
3. 选择“加载未打包的扩展程序”。
4. 选择当前 `temu-image-collector` 目录。
5. 刷新 Temu 商品列表页。

## 使用

1. 在商品卡片左上角点击“采集”。
2. 点击“全选可采集”可选中当前已加载的全部卡片。
3. 在右下角工具条选择采集模式。
4. 可选：勾选“采集商品标题”。开启后标题写入文件名、完整采集目录、`采集结果.json` 和 ZIP 根目录的 `商品标题.txt`。文件名中的标题会截断，完整标题以文本清单为准。
5. 可选：点击“选择保存目录”。授权后 ZIP 会直接写入该目录；未选择时使用浏览器默认下载目录。
6. 点击“开始采集”。
7. 采集完成后 ZIP 会写入所选目录或以默认下载方式保存。

采集过程中可点击“停止采集”。扩展会把当前已经下载成功或已经读取到的图片生成 ZIP，不会直接丢弃。若 Quick look 不存在，扩展会回退到卡片首图并把警告写入 ZIP 内的 `采集结果.json`。

批量采集时色值选项可能比轮播图更晚加载。v0.3.0 会等待并重新识别色值，不再依赖色值缩略图先加载完成；如果色值区域存在但仍无法识别，日志会显示对应商品 ID。尺码组会被明确排除，无法确认色值组时只保存默认图，不会按尺码重复采集。点击后未选中、标记为售罄或轮播图没有变化的色值会被跳过，不再复用上一色值的图片。

遇到 Temu 登录页或安全验证页时，扩展会暂停并保存任务进度，不生成半成品 ZIP。完成验证并返回 Temu 商品页后，点击“继续采集”即可恢复，已经完成的商品不会重复打开 Quick look。临时失败商品会在主批次结束后自动重试一次；仍失败的商品会保留，按钮变为“重试失败项”。

任务完成后的统计会分别显示：

- 已处理商品 / 已选商品
- 未处理商品
- 图片成功 / 失败
- 跳过色值
- 默认单色回退

工具条中的“清理 Temu 缓存”会清除当前 Temu 站点的 HTTP 缓存、Cache Storage 和 Service Worker，但不会清除 Cookie、账号或登录状态。清理后建议刷新页面。

## 目录结构

ZIP 根目录包含模式和时间，例如：

```text
完整采集+2026-10-23_16-32-10/
```

完整采集进一步按以下层级保存：

```text
{商品ID}_{商品标题}/{色值}/01.jpg
```

## 已知限制

- 扩展只处理页面已加载的商品卡片；新滚动加载的卡片需要重新点击“全选可采集”。
- Temu 页面结构和 Quick look 交互变化后，需要更新 DOM 选择器。
- 人工安全验证、登录验证和访问限制需要用户在浏览器中自行完成。
- 图片版权和平台使用规则由使用者自行确认。
