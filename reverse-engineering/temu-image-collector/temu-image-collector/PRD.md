# Temu 商品首图采集器 PRD

## 1. 产品目标

在 Temu 商品列表页中，对用户勾选的商品执行四种采集任务：

1. 获取商品卡片当前展示的首图。
2. 打开商品的 Quick look，按色值获取每个色值的首图。
3. 打开商品的 Quick look，按色值获取每个色值下的全部轮播图。
4. 点击商品链接进入详情页，按色值获取详情页图片并读取完整商品标题；默认读取全部详情图，可选只读取每个色值的首图。

所有结果在浏览器本地处理。图片模式生成 ZIP；链接模式生成 TXT，不下载图片文件。文件名使用模式和本地时间，ZIP 内只包含 `图片/` 和 `商品标题.xlsx`，不再重复写入同名根目录。

## 2. 核心原则

- 不调用未公开的 Temu 商品接口。
- 不复制 Cookie、登录令牌或请求签名。
- 只读取页面已经渲染的 DOM 和图片 URL。
- 不向第三方服务器上传商品或图片数据。
- Quick look 不存在或无法打开时，降级为卡片首图并在结果中记录警告。
- 单个商品失败不阻断整批任务。

## 3. 采集模式

| 模式 | 操作 | 输出 |
| --- | --- | --- |
| 简单采集 | 直接读取商品卡片中的首图，不打开 Quick look | 每个商品 1 张图 |
| 多首图采集 | 打开 Quick look，逐色值切换并读取轮播第 1 张 | 每个商品每个色值 1 张图 |
| 完整采集 | 打开 Quick look，逐色值切换并读取该色值下的全部轮播缩略图 | 每个商品每个色值一个子文件夹 |
| 详情图采集 | 从列表进入商品详情页，逐色值读取详情页图片；默认全部，可切换为每色值首图 | `图片/商品ID_标题_详情图_色值_序号.ext` |

四种采集模式共用一个“采集商品标题”开关。开启时标题经过安全字符清洗和长度限制后写入图片文件名，同时在 ZIP 顶层生成 `商品标题.xlsx`，并与 `图片/` 文件夹并列。工作表格式与用户提供的标题模板一致：A 列为 `序号`，B 列为 `标题`；数据从第 2 行开始按 1、2、3…连续编号，B 列保存完整标题且不截断、不换行。关闭时仅使用商品 ID、色值和图片序号。

详情图采集额外提供一个“仅每色值首图”开关，默认关闭。关闭时读取详情页每个色值的全部可用图片；开启时每个色值只保留第一张。详情任务会保存当前商品和阶段，页面跳转后自动恢复，不要求逐个商品手动点击继续。

四种模式共用一个“仅导出图片链接（TXT）”开关，默认关闭。开启后仍执行商品、Quick look、色值或详情页解析，但跳过图片下载和 ZIP 生成。解析完成后先显示图片预览筛选窗口，用户删除的图片链接不进入文档。每行只包含一个图片 URL：

```text
{原图链接}
```

链接取 `sourceUrl`，不包含 `imageView2` 缩略参数；相同 URL 只输出一次。文档不写商品 ID 和商品标题。

### 3.1 自动翻页、数量和历史过滤

- 自动翻页开关默认关闭；开启后当前页计为第 1 页，可设置 1–100 页。
- 本次商品数按商品卡片计数，默认 `0` 表示不限；达到目标立即停止翻页并开始采集，未达到则继续加载下一页。
- 当前页有手动勾选时，第 1 页按勾选结果采集；后续页采集全部可采集商品。当前页没有勾选时采集全部可采集商品。
- 优先点击 `See more / 查看更多 / 加载更多`，其次滚动加载，最后尝试分页链接。
- 链接记录保存在 `chrome.storage.local`；图片或链接成功保存后才记为已采集。后续任务默认跳过，最多保留最近 100,000 条。
- 预览中删除的图片不记入历史；用户可手动清空全部记录。
- `过滤 AD` 从固定规则改为“是/否”选项，默认“是”；选择“否”时仅关闭 AD 过滤，推荐区仍跳过。

若商品没有 Quick look：

- 简单采集正常使用卡片首图。
- 多首图采集回退到卡片首图，色值记为 `默认`。
- 完整采集回退到卡片首图，色值记为 `默认`，并在任务摘要中标注“未找到 Quick look”。

## 4. 输出结构

文件名使用本地时间，精确到分钟。ZIP 文件名中的空格、斜杠和冒号会替换为安全字符，确保 Windows 可解压使用。ZIP 内部不重复放置与文件名相同的根目录，避免解压后出现两层同名文件夹。

### 4.1 简单采集

```text
简单采集+2026-10-23_16-09-45.zip
└─ 简单采集+2026-10-23_16-09-45/
   ├─ 图片/
   │  ├─ 607569376602895_首图.jpg
   │  └─ 607423347706194_首图.jpg
   └─ 商品标题.xlsx
```

### 4.2 多首图采集

```text
多首图采集+2026-10-23_16-09-45.zip
└─ 多首图采集+2026-10-23_16-09-45/
   ├─ 图片/
   │  ├─ 607569376602895_Grey_首图.jpg
   │  ├─ 607569376602895_Navy-Color_首图.jpg
   │  ├─ 607569376602895_Black_首图.jpg
   │  └─ 607569376602895_fern-green_首图.jpg
   └─ 商品标题.xlsx
```

### 4.3 完整采集

```text
完整采集+2026-10-23_16-09-45.zip
└─ 完整采集+2026-10-23_16-09-45/
   ├─ 图片/
   │  └─ 607569376602895_Mens-Cargo-Pants/
   │     ├─ Grey/
   │     │  ├─ 01.jpg
   │     │  ├─ 02.jpg
   │     │  └─ 03.jpg
   │     ├─ Navy-Color/
   │     │  ├─ 01.jpg
   │     │  └─ 02.jpg
   │     └─ Black/
   │        └─ 01.jpg
   └─ 商品标题.xlsx
```

`商品标题.xlsx` 和 `图片/` 是 ZIP 内仅有的两个顶层项目。采集过程中的统计、失败和警告继续显示在扩展工具条日志中，不再额外生成 `采集结果.json`。

### 4.4 详情图采集

```text
详情图采集+2026-11-03_16-30-00.zip
└─ 详情图采集+2026-11-03_16-30-00/
   ├─ 图片/
   │  ├─ 607569376602895_Mens-Cargo-Pants_详情图_Grey_01.jpg
   │  ├─ 607569376602895_Mens-Cargo-Pants_详情图_Grey_02.jpg
   │  └─ 607569376602895_Mens-Cargo-Pants_详情图_Black_01.jpg
   └─ 商品标题.xlsx
```

详情图采集默认读取全部详情图；开启“仅每色值首图”后每个色值只保留 `01.ext`。商品和色值只写入文件名，不再创建商品、色值子文件夹。

### 4.5 图片链接文档

开启“仅导出图片链接（TXT）”时不生成 ZIP，直接保存：

```text
完整采集+2026-11-05_18-10-19.txt
```

内容示例：

```text
https://img.kwcdn.com/product/example-goods.jpeg
```

预览窗口显示图片缩略图、序号和源链接。每张图片提供“删除/恢复”按钮；底部显示总数、保留数和删除数。只有点击“确认导出”才生成 TXT；关闭窗口或点击“取消导出”则不生成文档。全部删除时“确认导出”按钮禁用。

## 5. 页面交互

### 5.1 商品选择

- 在商品卡片左上角注入采集勾选按钮。
- 点击按钮在“采集”和“已选”之间切换。
- 按卡片在视口中的纵坐标自动识别视觉行，每排至少 2 个可采集商品时，在该排最右侧卡片右上角注入“本排全选 / 本排不选”按钮。
- 同一视觉行只要已有商品被选中，行按钮显示“本排不选”；点击后一次取消该排全部已选商品。该排没有已选商品时显示“本排全选”。
- 页面滚动并加载新商品后自动补注入按钮。
- 浮动工具条显示可采集数量与已选数量。
- “Top picks for you / 为你推荐”等推荐区整组跳过；带可见 `AD` 标识的广告商品同样跳过。被跳过的商品不注入选择按钮，不能被全选，也不会进入图片或 `商品标题.xlsx`。工具条显示本次扫描忽略的推荐/广告卡片数量。

### 5.2 浮动工具条

包含：

- 全选可采集
- 清空选择
- 模式选择：简单采集 / 多首图采集 / 完整采集 / 详情图采集
- 采集商品标题开关
- 仅导出图片链接（TXT）开关，默认关闭；开启后不下载图片、不生成 ZIP
- 链接模式预览筛选窗口：缩略图、序号、链接、删除/恢复、恢复全部、确认导出和取消导出
- 图片模式“采集后图片小图预览”：确认打包、取消打包、删除/恢复和恢复全部
- 自动翻页开关、页数输入（当前页算第 1 页）和本次商品数输入（0 表示不限）
- 过滤 AD“是/否”选择，默认“是”
- 重复链接“跳过/保留”选择，默认“跳过”；显示已记录链接数量并支持清空
- 详情图采集专用的“仅每色值首图”开关；仅在详情图模式显示，默认关闭
- 保存目录选择：可直接写入用户授权的文件夹，未选择时使用浏览器默认下载目录
- 清理 Temu 缓存：清理 HTTP 缓存、Cache Storage 和 Service Worker，不清 Cookie
- 开始采集
- 继续采集 / 重试失败项 / 放弃任务
- 进度和错误摘要
- 最小化
- 标题栏自由拖动，自动限制在浏览器可视区域并记住位置

采集进行中禁用重复启动。完成后恢复按钮，并保留错误信息供查看。

拖动工具条时，标题和按钮文字不能被选中；双击标题栏恢复右下角默认位置。

## 6. 异常处理

- Quick look 打开超时：关闭残留弹窗，回退卡片首图。
- 某色值切换超时：继续尝试读取当前轮播；仍无图则记录该色值失败。
- 图片下载失败：对原图和无损参数地址最多重试 2 次。
- 单项失败：继续后续商品和色值。
- ZIP 无任何图片：不生成空文件，界面显示失败原因。
- 用户切换页面或刷新：保存任务进度和已读取的 Quick look 数据，返回 Temu 页面后可继续。
- 用户点击停止：不再读取后续商品，并将当前已经获取的图片生成 ZIP 保存。
- 检测到登录页或安全验证页：暂停任务，不自动下载半成品；验证完成后可继续。
- 失败重试：主批次结束后自动重试失败商品一次；仍失败时保留失败队列，按钮切换为“重试失败项”。
- 详情图跳转：任务记录当前商品和主采集/重试阶段，每进入一个详情页自动续采；安全验证页面沿用暂停逻辑。
- 自动翻页没有更多商品：在最后可用页停止，并记录“未找到下一页”警告。
- 目标数量大于页面可用商品：翻到页数上限或列表末尾后，以实际商品数继续采集。
- 重复过滤后无新图片：不生成空 ZIP 或空 TXT，任务暂停并显示跳过数量。

## 7. 非功能要求

- 单次采集不应占满主线程；下载并发默认 5。
- 单张图片超时默认 20 秒。
- Quick look 打开/关闭使用串行操作，防止多个弹窗互相覆盖。
- 不使用 jQuery、Layer 等旧前端依赖。
- 不包含无用大型库。
- 图片下载和 ZIP 生成全部在本地完成。

## 8. 验收标准

1. 在窗口 #7433 的 `mall.html` 页面能识别商品卡片和 Quick look。
2. 简单采集生成的 ZIP 文件名包含模式名和采集时间，ZIP 内顶层只有 `图片/` 与 `商品标题.xlsx`。
3. 多首图采集对测试商品生成 4 个色值首图。
4. 完整采集对每个色值生成独立子文件夹，文件按轮播顺序编号。
5. Quick look 不存在的商品不会中断整批任务。
6. ZIP 可在 Windows 资源管理器中正常打开。
7. 页面刷新后不残留不可点击的遮罩或采集状态。
8. 详情图采集能从列表连续进入多个详情页，默认读取全部色值图片，开启“仅每色值首图”后每个色值只保留一张。
9. 开启链接模式后先显示预览窗口，只生成 TXT，每行只有一个图片链接；窗口中删除的链接不出现，且不产生 JPG/PNG 图片文件。
10. 自动翻页设置 3 页、目标商品 8 个时，加载到第 8 个商品立即停止，不继续第 3 页。
11. 第二次采集相同列表时，已确认图片链接被跳过；上次在预览中删除的链接仍可再次出现。
12. AD 过滤选择“是”时跳过 AD，选择“否”时可选择非推荐区 AD 商品。
13. 图片模式完成读取后显示小图预览，确认后生成 ZIP，取消后不生成。

## 9. 当前范围外

- 图片裁切、排版、AI 抠图和首图设计。
- 自动上传到 Temu 卖家后台。
- 绕过登录、验证码、风控或访问限制。
- 云端任务队列、多设备同步。
