VF

VISUAL FORGE / CONNECTOR

Muse 对话框连接设置

图片模型配置

产品文生图和裂变直接由扩展调用。演示模式不消耗外部额度。

对话指令

在 Muse 输入框键入以下指令并按 Enter。扩展只拦截以 /vf 开头的内容。

同一商品多个指定色号
/vf product-colors #1D2A44,#8C1A2D --names 藏青,酒红
一个 Logo 多个颜色
/vf colors #111111,#FFFFFF
多个 Logo 统一颜色
/vf color #D4684F
产品文生图与裂变
/vf generate 极简陶瓷杯 --count 4 --size 1024x1024

Logo 指令需要先在浏览器右侧的 Visual Forge 侧栏中选择素材。产品裂变不需要上传素材。

边界

  • 扩展不读取 Muse 的历史聊天或普通对话内容。
  • 商品多色模式只读取本次指令后新生成的任务图片，用于本地校色和质检。
  • 扩展不自动登录；商品配色只会在你点击“开始逐色生成”后提交当前目标色号。
  • 任务历史和图片保存在浏览器扩展的 IndexedDB 中。
  • 归档目录在挂件顶部选择；浏览器重启或权限失效后需要重新授权。
  • 模型 Key 按当前产品要求保存在 chrome.storage.local，不提供系统级密钥库保护。
  • 不需要启动 Python、Visual Forge 本地服务或访问本机 API。
  • “回填 Muse”只把摘要写入输入框，发送动作由你确认。
