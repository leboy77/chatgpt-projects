# Visual Forge for Muse

版本：`0.13.1`

这是一个 Chromium Manifest V3 扩展。它把 Muse 页面作为图片和视频生成入口，并在扩展内部完成任务历史、图片处理、视频归档、精确校色、ΔE2000 质检、ZIP 和目录归档。

当前版本**不需要启动 Python 后端，不调用 `127.0.0.1:8765`，也不依赖 `.env` 文件**。

挂件可从上下左右和四个角自由拉伸；顶栏 A−/A+ 或 Ctrl + 鼠标滚轮可调整界面与字体大小。默认字体缩放为 110%，窗口尺寸和字号都会自动记忆。

“仅下载图片链接”开启后，Muse 任务的授权目录只写入 `图片链接.txt`、`图片链接.json` 和 README，不写入图片文件。每个成功任务卡也可单独点击“下载图片链接”。Muse 临时链接可能过期，需要长期保存时请关闭该开关。

“Muse 返回后立即下载”默认开启。Muse 每返回一批图片或视频，扩展会立刻把媒体下载到浏览器默认下载目录下的 `VisualForge自动保存\YYYY-MM-DD\任务名`，不再等到整条任务结束。该下载是保护副本，不影响最终授权目录归档；即使最终归档失败，已经下载的媒体仍会保留。

产品和技术基线：

- `..\docs\PRD.md`
- `..\docs\技术设计文档.md`
- `..\docs\CHANGELOG.md`

修改扩展功能时必须同步更新上述文档。

## 首次配置

### 1. 安装扩展

1. 在 BitBrowser 或 Chrome 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择：

```text
..\muse-extension
```

5. 打开或刷新 <https://muse.ai/>。
6. 点击扩展工具栏图标，打开页面内 `VF` 挂件。

扩展更新后需要执行：

1. 在 `chrome://extensions` 点击扩展“重新加载”。
2. 刷新 Muse 页面。

### 2. 选择归档目录

在挂件顶部点击“自动保存到授权目录”右侧的“选择”：

1. 扩展会打开独立的目录授权页。
2. 首次选择点击“选择新目录”；
3. 已有目录权限失效时点击“重新授权当前目录”。
4. 选择新目录时，在系统窗口中选择任意可写文件夹。
5. 关闭授权页并返回 Muse。

后续任务会在授权文件夹中自动创建任务目录。

任务目录时间固定使用中国标准时间 `Asia/Shanghai`，不受 BitBrowser 窗口代理时区影响。

浏览器重启、扩展重载或浏览器撤销目录权限后，需要重新打开目录授权页并确认权限。已完成任务仍保留在 IndexedDB 中，可以通过任务卡重新授权并保存。

“重新授权当前目录”只申请原目录权限，不会打开文件夹选择器；需要换位置时请使用独立的“选择新目录”按钮。

### 3. 配置图片模型

点击挂件右上角设置，打开扩展选项页：

- 演示模式：使用扩展内置占位图，不访问网络、不消耗模型额度。
- OpenAI 兼容模式：填写 API 地址、模型名称和 API Key。

默认示例：

```text
API 地址：https://api.openai.com/v1
模型名称：gpt-image-1
```

保存时会请求该模型域名的可选网络权限。API Key 保存在 `chrome.storage.local`。

> 当前产品按需求暂不提供 Windows Credential Manager、DPAPI 或 Native Messaging。任何能读取扩展数据的人都可能取得该 Key，因此不要在共享电脑或不可信浏览器配置中使用高权限密钥。

## 功能

### 商品配色

1. 添加一张商品主图。
2. 输入一个或多个 HEX 色号。
3. 可使用原生取色器、屏幕吸色、主图吸色和最近颜色。
4. 可选上传商品遮罩，选择商品主体、上装或下装。
5. 可选择逐色稳定模式，或让 Muse 一次返回 1-4 个颜色；批量数量异常、重复或失败时自动逐色保底。
6. 扩展使用 Canvas 像素处理把商品区域校正到指定 HEX。
7. 计算 sRGB、Lab 和 ΔE2000：
   - `ΔE <= 3`：通过
   - `3 < ΔE <= 5`：复核
   - `ΔE > 5`：需重试
8. 成功结果自动保存到授权目录。
9. 商品配色、Logo 多色、Logo 重绘、印花套图和产品裂变都能保存到任务列表并一键排队。
10. 失败色号可单独重试。

每个商品颜色输出：

```text
NN-色号.png              精确校色成品
NN-色号-muse-raw.png     Muse 原始结果
NN-色号-mask.png         实际使用遮罩
contact-sheet.png        颜色对比图
manifest.json
manifest.csv
README.txt
```

### Logo 多色

一个 Logo 生成最多 30 个颜色版本。扩展保留透明通道，不破坏抗锯齿边缘；纯色背景可自动去除。

### Logo 重绘

上传 1 张完整商品主图，填写新 Logo 设计要求。Muse 会直接重绘商品图中已经存在的 Logo：

- 删除旧 Logo，并在原位置和透视下生成一套新的 Logo 设计。
- Prompt 要求商品版型、印花、背景、构图、裁切、光影和非 Logo 区域保持原样。
- 输出 Muse 重绘成品、源图、JSON、CSV 和 README。
- 可选择逐张稳定模式，或自定义请求次数和每次返回 1-4 张；批量失败时自动逐张保底。
- 请求次数与“每批数量”分开配置，界面实时显示总图片数。
- “保存 / 更新”修改当前任务；“新增 Logo 重绘任务（不覆盖）”会创建独立任务，不影响已加载任务。

### 产品视频

上传 1 张商品主图，通过 Muse 生成商品展示视频：

- 展示方式支持“商品独立展示”“模特上身 · 严格不露脸”和“产品细节 + 模特上身 · 不露脸”。
- 商品类目支持自动识别、上装、下装、连衣类、套装和其他。
- 支持约 5、8、10 秒以及 9:16、1:1、16:9。
- 可自定义请求次数；每次请求生成 1 个视频，整次配置只保存为一任务。
- Muse 返回视频后在“Muse 最近返回”区域直接播放，并按即时下载开关保存。
- 单个请求失败自动重试 1 次；仍失败时记录失败请求，可点击“重试失败视频请求”。
- 只要出现真人模特，脸部必须完全出画；仅允许颈部以下入镜，禁止正脸、侧脸、完整头部和脸部特写。即使用户删掉模板里的相关句子，发送前仍会自动补回硬约束。
- 产品视频任务可保存、加载、复制并加入统一任务队列。

### 文案生图与商品裂变

上传 1 张商品主图，再输入文案或场景描述。扩展使用图生图接口逐张生成：

- 主图作为每次请求的商品身份参考。
- 空白状态不能提交，多张主图会被拒绝。
- 默认使用 Muse 页面图生图，也可切换为已配置的图片模型。
- 产品裂变使用单一简单模板：保持原主图构图、机位、裁切、商品位置和比例，只改裤子表面的印花与配色。
- “本次裂变描述”可留空；留空时仍执行换印花、随机非白底布和风格化背景。
- 每张自动从深灰、深蓝、酒红、橄榄绿、焦糖、雾紫等非白色中随机改变当前商品类目的底布。
- 图片背景不再使用纯色，而是根据当前印花风格生成协调的场景、纹理、色彩和光影。
- 新增“背景处理”选项：默认“随印花改变背景”，也可选择“保持原主图背景”；配置随任务保存。
- 默认使用“全部风格混合（推荐）”，每次随机排序 72 个方向；也可切换到优先遵循提示词的智能导演，或选择亚比机车、街头、暗黑机能和综合商业视觉。
- 商品类目可选择自动识别、上装、下装、连衣类、套装和其他；上装模式只处理上装正背面与袖子印花区域，不再套用裤子或裤底描述。
- 所有模板风格都受工厂平面印花约束：只使用哑光平涂、矢量或网点印花，不表现高光、浮凸、立体装饰或特殊表面效果。
- 主界面不再显示“提示词模板版本”下拉框，只保留一套产品裂变模板；视觉印花方向仍由“视觉风格包”控制。
- “全部风格混合”每次任务都会随机打乱 72 个方向，避免始终从同一方向开始。
- 一次产品裂变配置只创建一条任务；内部多次调用 Muse 仍只算同一条任务。
- 可分别自定义“请求次数”和“单次返回张数”；一次 Muse 对话返回 1-4 张，默认 4 张。例如 10 次对话、每次 4 张会生成 40 张，但只发送 10 次对话请求。
- 默认每一版都从原主图开始，避免连续生成累积版型和结构变化；也可以手动选择上一版结果作为下一版主图。

任务列表：

- 商品配色、Logo 多色、Logo 重绘、印花套图、产品裂变和产品视频都有独立保存按钮。
- 每条任务保存输入图片 Blob、请求方式、输出设置和模式专属参数，刷新后仍能加载运行。
- 列表支持加载配置、复制最近任务、运行单条和删除。
- “另存为新任务（不覆盖）”会解除当前任务关联，下一次保存创建新任务，不覆盖原任务。
- 每张任务卡可输入任意正整数复制次数 X，一次复制出 X 条独立待运行任务，不设产品上限。
- 点击“一键排队全部任务”后，按创建时间逐个运行，单条失败不会阻止后续任务。
- 队列面板显示成功、失败、自动保存和未保存数量。
- 可暂停或继续队列；失败任务支持一键重试。
- 任务保存在浏览器 IndexedDB，刷新页面后不会丢失。
- 每次对话支持返回 1-4 张图片，请求次数可输入任意正整数；全部输出保存在同一任务和一个归档目录。
- 支持 `1024x1024`、`1536x1024`、`1024x1536`。
- 自动使用 8 个场景方向：棚拍、生活方式、材质特写、节日、杂志、平铺、户外、礼品。
- 模型引擎每张图片单独调用 `/images/edits`，并携带主图、文案、尺寸、质量和保真约束。
- 演示模式会把上传主图合成到不同本地场景中，用于验证图生图链路。

提示词模板与记忆：

- “提示词模板”页完整展示 8 个默认 Prompt；产品裂变只有“固定构图换印花”一套，产品视频包含独立的“商品展示”模板。
- 每个模板可单独恢复默认，也可以统一保存；模板变量由对应功能自动填充。
- 产品裂变模板可以不包含 `{{instruction}}`。
- 产品裂变可勾选“直接发送用户提示词”，此时扩展不添加任何模板包装。
- 记忆模式默认开启，最多保留最近 20 条主图、描述和任务配置；可恢复或删除。

归档目录是可选的。所有模式都会先生成并保存到 IndexedDB；目录已授权时每条成功任务自动归档，未授权时任务不会被阻止，恢复授权后可在任务卡中再次归档。

Muse 对话控制：

- 勾选“自动回复继续”后，插件只在自身等待生成结果期间监控 Muse 新回答。
- “Muse 返回后立即下载”默认开启；每批 Muse 图片或视频返回后立即保存到浏览器下载目录，与最终任务归档相互独立。
- 明确询问“是否继续 / 是否需要继续 / continue?”时，优先点击继续按钮，否则发送“继续”。
- 历史确认消息不会触发回复，输入框已有用户草稿时也不会覆盖。
- 可叠加开启“5 分钟无响应自动继续”：Muse 五分钟没有产生结果时再次发送“继续”。
- Muse 明确回复“没做出来、暂时做不了、换新对话、先做第 N 个、你看怎么安排”等内容时，不再反复发送“继续”；插件等待 15 秒补图，仍无图片就把当前颜色/参考图/批次记为失败并继续后续项。
- 默认单图最多等待 90 秒、批量最多等待 120 秒、视频最多等待 10 分钟；开启 5 分钟无响应兜底时保留 30 分钟长等待。
- Muse 提示“当前对话图片太多、队列已满、达到上限”时，插件自动打开 `https://muse.ai/thread/new` 的空白新对话并重试当前请求。不会再打开会恢复 Main chat 的 `https://muse.ai/` 首页。
- 提示“对话记录超过上限、聊天太长做不了图”时同样进入空白新对话并重试当前批次。
- 10 分钟内最多自动打开 2 个恢复窗口；如果新窗口仍提示容量不足，插件跳过当前不可解决项并继续任务队列。
- 生成图片一出现就会被独立记录，即使运行中向上滚动、消息被 Muse 重新渲染或暂时移出 DOM，也不会漏图。
- 历史图片重新挂载时会按图片 URL 去重，不会再次下载或触发重复对话请求。
- 可开启“纯文本失败自动回复‘重新生成’”：Muse 只回复文字且 20 秒没有图片时，插件自动发送一次“重新生成”。
- 第二次仍只有文字时跳过当前颜色、Logo、参考图或产品裂变轮次，并记录成功/失败数量。

### 印花套图

输入：

- 1 张白底商品图。
- 1 个参考图文件夹。
- 可选商品类目；选择上装时 Prompt 会锁定上装正面、背面和袖子印花区域。

扩展会在浏览器内：

1. 过滤非图片和超过 24MB 的单张参考图。
2. 按文件名排序，全部有效参考图都参与处理；超过 200 张也不会截断。
3. 每批参考图/返回张数可设置 1-4 张，原始总大小尽量不超过 24MB。
4. 生成必须小于 25MB 的 ZIP；超出时继续拆分。
5. 逐张模式每次给 Muse 一张参考图。
6. 多图 Agent 模式每批上传白底图和 ZIP，要求 Muse 返回数量一致的独立图片。
7. 批量结果数量不符、重复、等待不完整或出现 `Delivery not confirmed` 时，不映射错误图片，自动降级为逐张生成。
8. 每张参考图只输出一张新图，禁止拼图和九宫格。
9. 保持白底图背景，或让背景随印花风格改变。
10. 失败参考图可单独重试。

## Muse 对话指令

```text
/vf colors #111111,#FFFFFF [--sku 货号]
/vf color #D4684F [--sku 货号]
/vf generate 文案或场景描述 --count 4 --size 1024x1024 --quality high [--sku 货号]
/vf product-colors #1D2A44,#8C1A2D --names 藏青,酒红 --region lower [--sku 货号]
```

扩展只拦截用户主动输入并以 `/vf` 开头的消息，不读取历史聊天或普通对话。

## 任务历史和存储

任务记录保存在扩展 IndexedDB：

```text
visualforge-extension
├─ jobs      任务状态、参数、输出元数据和缩略图
├─ assets    原始图片/视频 Blob、JSON、CSV
├─ settings  用户授权的目录 Handle
├─ tasks     六个模式的完整任务配置与输入 Blob
└─ prompt_memories  最近的主图与提示词记忆
```

模型配置和最近使用颜色保存在 `chrome.storage.local`。

### Muse 即时下载目录

```text
浏览器默认 Downloads\
└─ VisualForge自动保存\
   └─ YYYY-MM-DD\
      └─ 任务名\
         └─ HH-mm-ss_批次01-NN_001_原文件名
```

同名文件会自动追加唯一后缀，不会覆盖旧下载。可在任务控制栏关闭“Muse 返回后立即下载”；开启“仅下载图片链接”时不会产生即时图片文件。浏览器若修改默认下载目录，后续文件会跟随新的下载目录。

浏览器重启、扩展重载或 Muse 页面刷新会中断当时正在执行的生成任务；已完成任务不受影响。被中断的任务会标记为失败，需要重新开始。

## 归档结构

普通任务：

```text
授权目录\
└─ 模块名_货号_YYYY-MM-DD_HH-mm-ss\
   ├─ 输出图片
   ├─ 源图
   ├─ manifest.json
   ├─ manifest.csv
   └─ README.txt
```

印花套图一次开始只创建一个任务根目录：

```text
授权目录\
└─ 印花套图_货号_YYYY-MM-DD_HH-mm-ss\
   ├─ 生成图\
   │  ├─ 批次01_...
   │  └─ 批次02_...
   └─ 拼图与清单\
      ├─ 批次01_pattern-contact-sheet.png
      ├─ 批次01_manifest.json
      ├─ 批次01_manifest.csv
      ├─ 商品主图.png
      └─ README.txt
```

产品视频：

```text
授权目录\
└─ 产品视频_货号_YYYY-MM-DD_HH-mm-ss\
   ├─ 源图
   ├─ product-video-01.mp4
   ├─ manifest.json
   ├─ manifest.csv
   └─ README.txt
```

任务目录或同一秒创建的同名任务已存在时，会自动追加 `_2`、`_3`。

## 当前限制

- 浏览器关闭后不能继续执行生成任务。
- 扩展 Service Worker 休眠不影响已完成的 IndexedDB 数据，但不是常驻任务服务器。
- 目录授权由 File System Access API 管理，权限失效时必须重新授权。
- 模型 Key 只保存在扩展本地存储，不具备操作系统级密钥保护。
- Muse 页面改版可能影响输入框、附件、发送按钮或结果图片识别。
- Muse 账号是否开放视频生成、视频返回格式和生成时长由 Muse 服务端决定；扩展能识别常见视频附件，但不能保证每个账号都支持视频。
- 不确保恢复已经中断的模型请求或 Muse 生成请求。
