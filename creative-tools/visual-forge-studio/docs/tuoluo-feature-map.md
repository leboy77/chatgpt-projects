## 3. 通用生图工作台

页面结构固定为三段：

- 左侧约 380px 参数面板。
- 中间生成结果与任务详情。
- 右侧近期任务和“查看全部历史”。

### 输入模式

- 单张生成。
- 批量生成。
- 部分全印类目额外提供“一键拓品”，输入旧任务 ID 并选择目标类目。
- 单张生成可切换“上传图片”和“图片 URL”。
- 批量生成按工具接受 ZIP/RAR/7Z、TXT 或 JSON。
- 上传后显示图片或文件预览，可清空重选。

### 生图参数

- 参考图：作为主体与构图约束。
- 模型：通用模型、狂野模型。
- 重绘幅度：默认 75%，实际任务入参通常按 0.5 或用户比例换算。
- 生成数量：页面提供 1、2、3、4 档，后台支持更大批量。
- 生图比例：默认 3:4；比例列表由后端动态下发；3:4 标记为推荐。
- 生成商品标题：可开启，调用 AI 生成英文标题。
- AI 云过滤：可开启，过滤违规或低质量内容。
- 批量关键词过滤：上传 TXT，每行一个关键词。
- 参数重置。

### 提交与计费

- 提交前请求积分预估。
- 弹窗展示预计消耗积分、预计得到商品数量、退款规则。
- 用户确认后才创建任务。
- 通用模型基础价约 8 积分，狂野模型约 10 积分；实际费用会叠加处理项。
- 失败会按任务阶段回充积分；已进入生成阶段的条目通常不退。

### 任务状态

- 等待中。
- 准备中。
- 生成中。
- 处理中。
- 图片上传/加载中。
- 任务完成。
- 部分成功。
- 失败。
- 已取消。

### 结果操作

- 原图与生成图并排查看。
- 多图横向滚动、放大预览、效果对比。
- 查看任务 ID、货号、类目、模型、比例、数量、重绘幅度、违规过滤与扣费信息。
- 编辑或保存单图标题。
- 删除单图或删除整条创作。
- 下载单图、高清图、生成图、矢量图、套图和上货数据。
- 中止尚未进入不可逆阶段的生成任务。
- 按类目、任务类型、货号/上家 ID、时间范围筛选。
- 按状态筛选：全部、成功、失败、其他。

## 9. 全印工作台

### 生图套图

- 单张、批量、一键拓品。
- 选择多个全印类目模板。
- 多模板套图。
- 模板可带预设颜色，多色模板可以为多个颜色一次生成。
- 自动印花提取。
- 可跳过提取，只用已有设计图继续套图。
- 自动图生图。
- AI 违规过滤。
- 整套商品套图。
- 自动高清放大。
- 自动英文标题。
- 矢量图保存。
- 云存储。
- 批量输入数据必须包含稳定货号。

### 提取/套图

- 上传参考图并选择类目模板。
- 可走完整“提取 + 套图”，也可仅做模板套图。
- 根据参考图或数据生成英文商品标题。
- 每个全印类目约 2 积分。
- 输出原图、提取图、套图、合成图与下载包。

### 图案分类

- 按图案语义自动分组。
- 每组生成多规格商品结构。
- 中英文组名和规格名可编辑。
- 支持新建组、删除空组、单条移动、批量移动。
- 支持每类商品数量上限。
- 小组自动凑批；异常数据由 AI 再分类后均分。
- 分类前按计费数据条数预扣积分，整体失败可退。
- 多色多颜色类目默认不参与分类。

## 14. 原站技术与权限现象

- 前端为 Vue 2 + Element UI，Webpack 分包。
- 路由使用 history 模式。
- 业务接口集中在 `/ERP/*`，登录使用 `/login`、`/getInfo`、`/captchaImage`。
- 实时任务通知使用 SignalR。
- 菜单和按钮由后端权限动态下发。
- 全印权限按钮标签：`ai:fullprint:gen`。
- 切图权限按钮标签：`ai:cutting:manage`。
- 直接打开某些动态路由会进入 `/404`；从首页入口点击才正常加载。

## 15. MUSE Visual Forge 复刻策略

第一阶段保留原站最有效的产品结构，但不复制其品牌和素材：

- 深色创作台。
- 类目卡片入口。
- 左侧参数、中间结果、右侧任务列表。
- 登录/注册。
- 首页、生图、处理工具、模板、切片、历史、素材、积分、个人中心导航。

我们自己的差异化业务优先接通真实能力：

- 单 Logo 多色，保留透明边缘与抗锯齿。
- 多 Logo 统一品牌色。
- 商品多色的 Muse 生成图回收、遮罩、精确 HEX 校正与 ΔE2000 质检。
- 产品视觉裂变，输出 PNG、JSON、CSV 和 ZIP。
- 任务持久化、异步队列、重试与可恢复。

第一阶段不伪装成已经具备原站所有 AI 后端能力。尚缺模型、模板 JSON、打印文件格式或切图配置的功能会在界面标明接入状态，并保留完整数据结构与操作入口。
