## 1. 产品定义

Visual Forge 是面向 POD 商品团队的纯浏览器视觉生产工具。用户已登录的 Muse 页面负责商品配色和印花图片生成，扩展自身负责：

- `/vf` 指令和 Muse 页面操作。
- 图片回传、ZIP 分批和任务编排。
- Logo 换色与商品精确校色。
- ΔE2000 质检。
- IndexedDB 任务历史。
- 文案生图（单主图图生图）和商品裂变。
- 可查看、编辑和恢复默认的产品裂变提示词模板。
- 可选的提示词与主图记忆。
- 自定义目录授权和自动归档。
- Muse 产品展示视频生成和视频归档。

当前版本不依赖 Python 服务、本机 HTTP API、`.env`、Native Messaging、DPAPI 或 Windows Credential Manager。

## 2. 目标与限制

### 2.1 产品目标

- 只安装扩展即可完成全部现有生产流程。
- 普通模块一次开始形成一个任务包；商品配色、Logo 多色、Logo 重绘、印花套图、产品裂变和产品视频都可保存为独立任务，内部多次 Muse 请求共享同一任务和归档目录。
- 任务列表可以一键按顺序排队运行全部模式任务。
- Muse 每返回一批图片后立即下载到浏览器下载目录，不等待整条任务完成；最终任务归档仍独立执行。
- 所有模式不依赖归档目录授权完成生成；未授权时先完成生成，授权后可再保存。
- 用户可指定任意可写目录；浏览器重启、扩展重载或权限失效后允许重新授权。
- 每张商品色结果可追溯到 Muse 原图、遮罩和 ΔE 数据。
- 产品裂变可直接调用模型，也可使用内置演示模型。
- Muse 返回图数量异常时禁止串图，并提供局部重试。

### 2.2 明确接受的产品限制

- 浏览器关闭后不能继续执行生成任务。
- Muse 页面刷新、扩展重载或浏览器重启会中断进行中的任务；已完成任务和历史保留。
- 目录权限由浏览器管理，权限失效时需要用户重新授权或重新选择目录。
- 浏览器若选择“仅这次访问时允许”，刷新或重启后仍可能再次询问目录权限；产品和 Logo 生成不再被此提示阻塞。
- 模型 Key 暂存于 `chrome.storage.local`，不提供操作系统级安全保护。
- 不保证恢复已经发出的模型请求；用户需要重新执行被中断任务。
- Muse 页面 DOM 改版可能导致适配器失效。

## 3. 用户流程

### 3.1 首次安装

1. 在 Chromium 中加载解压后的扩展目录。
2. 刷新 Muse 页面。
3. 可选：在扩展设置中选择演示模型或 OpenAI 兼容图片模型。
4. 在挂件顶部点击“选择”归档目录。
5. 在独立授权页选择或重新授权目录。

### 3.2 日常使用

1. 打开 Muse 页面并展开挂件。
2. 选择商品配色、Logo 多色、Logo 重绘、产品裂变、印花套图或产品视频。
3. 点击开始。
4. 扩展创建 IndexedDB 任务并显示进度。
5. Muse 每次返回图片或视频后，若“Muse 返回后立即下载”已开启，立即写入浏览器下载目录。
6. 整条任务完成后，扩展继续把完整结果自动写入授权目录。
7. 用户可查看缩略图、下载 ZIP、回填 Muse，或重新授权保存。


即时下载目录是浏览器默认下载目录下的保护副本，不等同于用户在扩展中授权的归档目录。即使任务最终归档失败或其中一批之后生成失败，已经即时下载的图片或视频仍保留。同名文件由浏览器自动追加唯一后缀，不覆盖既有下载。

- 产品裂变描述留空时仍可生成；每张按所选商品类目随机改变底布颜色，背景按印花风格生成，构图和商品位置保持原主图。
- 背景处理默认“随印花改变背景”，并可在任务中切换为“保持原主图背景”。
- Muse 每轮返回的图片立即显示在挂件“Muse 最近返回”区域。
- 挂件可从八方向自由拉伸，并记忆窗口位置和尺寸。
- A−/A+ 与 Ctrl+滚轮可调整界面和字体，默认字号为 110%。
- 开启“仅下载图片链接”后，授权目录只出现链接清单和 README，不出现 PNG/WEBP/JPG 图片。
- 任意任务可点击“另存为新任务（不覆盖）”，之后保存不会覆盖原任务配置。
- Muse 明确表示当前图片/批次失败时，插件不会继续发送“继续”；15 秒内没有补图就把当前项记为失败并继续后续项。
- Muse 提示当前对话图片过多或对话记录超限时，插件最多自动打开 2 个 `https://muse.ai/thread/new` 空白新对话；恢复后所有后续请求自动使用新对话标签页，且不会重新载入原 Main chat。
- 运行中可自由向上滚动查看历史对话；Muse 重渲染消息列表不会导致重复发送、漏图或重复下载。
- Muse 每批返回媒体后立即触发浏览器下载，完整流程模拟触发 20 次即时下载，其中包含 1 个视频。
- 即时下载不替代最终任务归档；即使最终归档失败，已经下载到浏览器目录的图片仍保留。
- “纯文本失败自动回复‘重新生成’”默认关闭，可在任务控制栏开启；二次失败后当前颜色/图片/批次记为失败并继续后续项。
- 所有模板模式最终 Prompt 都包含工厂平面印花约束；即使用户模板删除，也会在发送前自动补回。
- “提示词模板版本”只影响 Prompt 写法，“视觉风格包”才决定画面方向；全部风格混合每次随机排序。
- 工厂印花 Prompt 的正向方向描述已移除强质感词，印花只呈现普通染料墨水般的哑光二维效果。
- 产品裂变直传模式不拼接默认模板。
- 默认使用“全部风格混合”并随机排序 72 个方向；智能导演仍可选，并优先遵循用户提示词。
- 模拟 Muse 询问“是否继续”后，插件自动回复“继续”并继续等待结果。
- 虚拟归档目录与文件结构。
- IndexedDB 历史与归档完成顺序。

### 8.5 人工验收

- 目录授权页可选择、重新授权目录。
- 无归档权限时任一模式仍能生成，任务卡明确提示稍后归档。
- Muse 登录后商品配色和印花生成可完成。
- 在产品裂变页修改提示词模板并重新打开挂件后，模板仍保留。
- “提示词模板”页可查看并保存所有 8 个 Muse 提示词版本。
- 开启产品裂变“直接发送用户提示词”后，Muse 输入框内容与用户填写内容一致。
- 保存产品裂变任务后，记忆区出现主图缩略图，可恢复和删除。
- Logo 重绘归档中包含源图、Muse 成品、JSON、CSV 和 README。
- Muse 返回一批图片后，浏览器 `Downloads\VisualForge自动保存` 下立即出现对应文件。
- 关闭“Muse 返回后立即下载”后不再产生即时下载，但任务完成归档仍正常。
- 开启“仅下载图片链接”后不产生即时图片文件，只保留链接清单。
- 上传一张商品主图并选择“模特上身 · 严格不露脸”，确认 Muse 返回视频且脸部始终不入镜。
- 保存产品视频任务后刷新页面，确认主图、展示方式、时长、比例、补充描述和请求次数可恢复并排队。
- 在产品裂变、印花套图和产品视频中切换“上装 / 下装 / 连衣类 / 套装”，确认 Prompt 类目和任务卡信息同步变化。
- 任务结果自动写入授权目录。
- 浏览器关闭后重新打开，历史仍存在，进行中任务标记中断。
