## 1. 产品定义

Visual Forge 是面向 POD 商品团队的纯浏览器视觉生产工具。用户已登录的 Muse 页面负责商品配色和印花图片生成，扩展自身负责：

- `/vf` 指令和 Muse 页面操作。
- 图片回传、ZIP 分批和任务编排。
- Logo 换色与商品精确校色。
- ΔE2000 质检。
- IndexedDB 任务历史。
- 产品文生图和裂变。
- 自定义目录授权和自动归档。

当前版本不依赖 Python 服务、本机 HTTP API、`.env`、Native Messaging、DPAPI 或 Windows Credential Manager。

## 2. 目标与限制

### 2.1 产品目标

- 只安装扩展即可完成全部现有生产流程。
- 一次点击形成一个任务包，完成后自动归档。
- 用户可指定任意可写目录；浏览器重启、扩展重载或权限失效后允许重新授权。
- 每张商品色结果可追溯到 Muse 原图、遮罩和 ΔE 数据。
- 产品裂变可直接调用模型，也可使用内置演示模型。
- Muse 返回图数量异常时禁止串图，并提供局部重试。

### 2.2 明确接受的产品限制

- 浏览器关闭后不能继续执行生成任务。
- Muse 页面刷新、扩展重载或浏览器重启会中断进行中的任务；已完成任务和历史保留。
- 目录权限由浏览器管理，权限失效时需要用户重新授权或重新选择目录。
- 模型 Key 暂存于 `chrome.storage.local`，不提供操作系统级安全保护。
- 不保证恢复已经发出的模型请求；用户需要重新执行被中断任务。
- Muse 页面 DOM 改版可能导致适配器失效。

## 3. 用户流程

### 3.1 首次安装

1. 在 Chromium 中加载解压后的扩展目录。
2. 刷新 Muse 页面。
3. 可选：在扩展设置中选择演示模型或 OpenAI 兼容图片模型。
4. 在挂件顶部点击“选择”归档目录。
5. 在独立授权页选择或重新授权目录。

### 3.2 日常使用

1. 打开 Muse 页面并展开挂件。
2. 选择商品配色、Logo 多色、多 Logo 同色或产品裂变。
3. 点击开始。
4. 扩展创建 IndexedDB 任务并显示进度。
5. 任务完成后自动写入授权目录。
6. 用户可查看缩略图、下载 ZIP、回填 Muse，或重新授权保存。

## 7. 非功能需求

| 编号 | 需求 |
| --- | --- |
| NFR-001 | 模型域名通过可选 host permission 授权 |
| NFR-002 | 模型 Key 不进入 Muse 页面上下文 |
| NFR-003 | 目录写入仅发生在用户选择的 Handle 内 |
| NFR-004 | 任务 Blob 保存在扩展 IndexedDB，不写入任意网页存储 |
| NFR-005 | 不自动登录 Muse，不读取普通聊天 |
| NFR-006 | 上传、任务参数和文件路径均做长度/格式约束 |
| NFR-007 | 关键算法和页面流程必须有自动化回归 |

### 8.5 人工验收

- 目录授权页可选择、重新授权目录。
- 无权限时任务不得开始，并给出清晰提示。
- Muse 登录后商品配色和印花生成可完成。
- 任务结果自动写入授权目录。
- 浏览器关闭后重新打开，历史仍存在，进行中任务标记中断。

## 9. 后续候选

- 浏览器关闭后的任务续跑需要 Native Messaging 或后台服务，不属于当前纯扩展范围。
- 可将模型 Key 改为用户口令加密或系统密钥库。
- Muse DOM 适配器可视化诊断。
- 更精细的手绘遮罩编辑器。
- 商品色白、黑、金属和反光材质的专项校色。
