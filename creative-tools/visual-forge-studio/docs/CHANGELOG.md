# Visual Forge 变更记录

本文件记录产品、技术、接口、归档和验收口径的变化。版本号按组件分别记录；后端包版本与扩展版本不要求相同。

## 2026-11-02 · 0.4.1 全流程虚拟测试修复

### 扩展

- 版本：`0.4.1`
- 修复挂件向任务执行器传入不存在的 `waitIfPaused`，导致任务点击开始后立即失败的问题。
- 图片解码增加 `createImageBitmap` 失败后的 `HTMLImageElement` 回退，支持 Muse 返回的 SVG/兼容格式。
- 商品色全部失败时，错误信息增加每个色号的具体失败原因。
- 调整任务状态顺序为“生成完成、正在归档、最终完成”，确保任务显示成功时自动归档已经结束。
- Logo 输出文件名移除源扩展名重复，例如由 `logo-a-png-...` 改为 `logo-a-...`。
- 新增 `full-flow-virtual.js` 完整虚拟验收。
- 更新签名安装包 `extension.crx` 和 `visual-forge-muse-0.4.1.zip`。
- 已在 BitBrowser 窗口 `#8358` 将扩展从 `0.4.0` 更新到 `0.4.1`，刷新 Muse 页面并确认挂件模块加载。

### 验证

- 全流程虚拟测试通过，5 个生产任务全部为 `succeeded`。
- 单 Logo 多色：2 张。
- 单色多 Logo：2 张。
- 商品配色：2 个颜色均通过，输出 7 张业务图片资产。
- 印花套图：2 张印花图和 1 张对比图。
- 产品裂变：暂停后保持 `running`，恢复后生成 4 张。
- 5 个任务均生成独立归档目录，印花目录结构符合要求。
- IndexedDB 历史记录数量为 5。

### 发现并确认的问题

- 任务启动控制参数命名错误。
- SVG 数据在 Canvas 任务中可能无法由 `createImageBitmap` 解码。
- 原状态机在归档完成前提前标记任务成功。

## 2026-11-02 · 0.4.0 纯扩展版本

### 扩展

- 版本：`0.4.0`
- 移除运行时对 `127.0.0.1:8765` 和 Python 后端的依赖。
- 移除 Manifest 中的 localhost/127.0.0.1 固定权限。
- 新增扩展内 IndexedDB 任务库：`jobs`、`assets`、`settings`。
- 新增浏览器 Canvas 图像处理：
  - Logo 背景去除、裁切和透明换色。
  - 商品自动遮罩、局部精确校色、sRGB 和 CIEDE2000。
  - 商品色对比图和印花对比图。
- 新增扩展内任务执行器，覆盖 Logo 多色、多 Logo 同色、产品裂变、商品配色和印花收尾。
- 新增浏览器端 mock 图片模型。
- 新增 OpenAI 兼容图片模型直连，使用可选 host permission 授权模型域名。
- 模型地址、模型名和 Key 改为扩展选项页配置；Key 保存到 `chrome.storage.local`。
- 新增 `directory.html` 独立目录授权页。
- 上传目录 Handle 持久化到 IndexedDB；浏览器重启、扩展重载或权限失效后支持重新授权。
- 归档目录支持用户自定义路径，任务目录自动创建和重名递增。
- 印花套图改为在扩展内预留任务根目录，多批次共享同一根目录。
- 商品配色、印花、Logo 批量和产品裂变中的可暂停步骤改为扩展内暂停。
- 历史任务在挂件关闭后继续保留；页面重载恢复已完成任务，进行中任务标记为中断。
- 移除任务创建、查询、暂停和归档对 background 本地 API 消息的调用。
- 更新签名安装包 `extension.crx` 和 `visual-forge-muse-0.4.0.zip`。
- 已在 BitBrowser 窗口 `#8358` 将扩展从 `0.3.5` 更新到 `0.4.0`，并刷新 Muse 页面。
- 已停止 `127.0.0.1:8765` 的 Python 服务；停止后 `#8358` 挂件仍正常加载并显示扩展模块。

### 后端

- Python 后端保留为历史实现，不再是扩展运行时依赖。
- 不修改后端代码。

### 验证

- 扩展单元测试：28 项通过。
- `background-smoke`：通过，确认旧本地 API 消息被拒绝。
- 真实 Chromium 扩展页面测试：通过。
  - Logo 多色 2 张。
  - 商品配色 ΔE 为 0、状态 `pass`。
  - 产品裂变 mock 2 张。
  - 印花收尾 2 张图。
  - 页面重载后 IndexedDB 历史恢复。
  - 模型设置页可保存，页面中不存在旧 `127.0.0.1:8765` 配置入口。

### 已知限制

- 浏览器关闭后无法继续执行任务。
- 模型 Key 没有系统级密钥库保护。
- 目录权限失效时必须重新授权。
- Muse DOM 改版仍可能影响生成链。
