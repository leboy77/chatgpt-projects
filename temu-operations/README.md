# Temu 运营工具

本分类收纳用于 Temu 商家后台的浏览器扩展、自动化脚本、需求文档和测试工具。

## 子项目

- [price-checker](price-checker/)：全球价格申报核价助手。
- [downlist-assistant](downlist-assistant/)：商品下架、图片保存、广告花费监控及相关工具合集。
- [auto-recolor](auto-recolor/)：SKC/SPU 商品批量新增色值、补图和自动提交助手。

各子项目的安装步骤、运行限制和验证状态以自身 README 与 `docs/` 为准。涉及真实店铺操作时，优先使用预览、试运行或小批量验证。
