## 本地验证

```powershell
node --test tests/*.test.mjs
node tools/simulate.mjs
node tools/build-extension.mjs
```

核心规则采取保守默认值：

- 用户填写的是每站点「申报价」，单位为人民币。
- 可选择人民币或美元；美元模式填写“1 USD = X RMB”后，上传表中的 RMB 价格自动换算为 USD 显示和比较。
- 国家价格表只要填写 RMB 价格，就会自动导入并启用该国家；未填写价格才保持禁用。
- 平台价大于或等于申报价时，直接保留平台价并提交。
- 平台价低于申报价时，自动还价至申报价或单独设置的还价目标。
- 同一站点/SKC 的 SKU 价格跨越申报价时，系统排除该组并提示人工处理。
- 正式模式点击“开始自动核价”后按批次自动提交；测试时可开启“仅预览”。
- 执行期间可点击“暂停任务”；进入提交阶段后需等待明确提交结果。
- 检查或开始核价时自动锁定目标标签页；切换到其他 Temu 后台标签不会改变核价目标或暂停目标。
- 同一个 Excel 同时维护 SKC 和 59 个国家的 RMB 价格参数，是唯一数据源。
- 导入后国家和价格以只读摘要展示，不在 UI 中重复选择或填写。
- 最近导入参数自动恢复。
- 重复核价默认跳过已提交成功的 SKU。
- 页面临时失败最多自动重试 3 次；提交结果未知时停止并要求人工核对。
