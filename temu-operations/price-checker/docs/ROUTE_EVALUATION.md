# 技术路线评估

日期：2026-10-22  
性质：基于需求、平台约束和预研假设的决策记录；不是生产页面实测统计数据。

## 1. 候选路线

### A. MV3 扩展 + DOM 自动化

扩展侧边栏负责业务 UI，内容脚本执行与用户手工操作相同的页面流程。

优点：

- 复用登录态。
- 用户安装和使用路径清晰。
- Excel、国家参数、预览和提交都在同一界面。
- 可逐项确认并记录页面反馈。

风险：

- Temu 前端结构升级会影响定位器。
- 复杂 SPA、Shadow DOM 或异步渲染需要可靠等待。
- 页面性能和数据量会影响扫描速度。

### B. 扩展 + 页面接口直连

读取或操作平台内部接口，减少 DOM 点击。

优点：

- 理论上读取速度快。
- 字段结构可能比 DOM 更清晰。

风险：

- 未公开接口可能变化或触发鉴权/风控。
- 提交请求签名、令牌和业务前置状态不透明。
- 绕过页面流程会增加合规与安全风险。
- 错误请求可能造成批量误提交。

### C. 外部 Playwright/CDP 自动化

独立 Node 程序连接比特浏览器或普通 Chrome。

优点：

- 开发调试和自动回归能力强。
- 能直接复用现有调试端口。
- 适合内部批处理和测试。

风险：

- 普通运营用户部署成本高。
- 浏览器启动参数、端口和进程状态增加支持成本。
- 不便于长期保持用户对每步操作的可见性和控制。

## 2. 初步评分

权重与分数用于对齐决策，正式立项前应通过真实页面测试校准。

| 指标 | 权重 | A DOM 扩展 | B 接口直连 | C 外部 CDP |
| --- | ---: | ---: | ---: | ---: |
| 业务链路可控性 | 25% | 4.5 | 2.5 | 4.0 |
| 用户体验 | 20% | 5.0 | 3.0 | 2.0 |
| 会话兼容性 | 15% | 5.0 | 4.0 | 5.0 |
| 可维护性 | 15% | 3.5 | 2.0 | 3.0 |
| 数据安全与合规 | 15% | 4.5 | 2.0 | 2.5 |
| 交付速度 | 10% | 3.0 | 2.5 | 4.0 |
| 加权总分 | 100% | **4.38** | **2.68** | **3.38** |

## 3. 模拟测试重点

虚拟测试不模拟服务端接口，而是对业务规则进行确定性验证：

- 50 条 SKC、多国家、多 SKU 的组合。
- 平台价大于、等于、小于申报价及混合 SKU 场景。
- 原币换算、金额精度和汇率缺失。
- 页面重渲染后的定位器重新绑定。
- 提交中断与幂等恢复。
- 错误页面结构下的 fail-closed 行为。

## 4. 决策

采用 A 作为主路线：

1. Manifest V3 侧边栏扩展。
2. 页面 DOM 适配层。
3. 本地业务规则和审计。
4. Playwright 作为开发期测试工具，不作为用户运行环境。
5. 页面接口仅保留只读增强的备选，不能先于真实接口审计进入提交链路。

## 5. 继续推进的条件

- 登录目标窗口并完成目标页面只读采集。
- 确认确认弹窗的 DOM 层级、同步/异步加载方式和全部站点字段。
- 确定币种与 RMB 的来源及换算责任。
- 用 1 个 SKC 完成 Dry-run。
- 确认真实页面对批量选择与批量确认的限制。
