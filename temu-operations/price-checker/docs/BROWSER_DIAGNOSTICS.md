# 浏览器与目标页面诊断

日期：2026-11-12
产品版本：0.8.0

## 动态发现

比特浏览器每个窗口使用独立调试端口，端口在窗口重启后会变化。开发工具不得写死端口或配置 ID。

查找顺序：

1. 获取当前 `BitBrowser` 进程 ID。
2. 读取这些进程正在监听的本地端口。
3. 请求 `http://127.0.0.1:<port>/json/list`。
4. 使用窗口控制台标题、Temu 页面 URL 和扩展 ID 确认目标窗口。
5. 通过 CDP 连接具体标签页。

生产扩展不依赖调试端口，只使用 Chrome 扩展 API。

## 目标页面条件

- URL：`https://agentseller.temu.com/newon/product-select`
- 已登录 Temu Agent Center。
- 页面存在「价格申报中」标签。
- 商品查询区域存在多个 SKC 输入框。
- 全选和「批量管理申报价」可用。
- 价格抽屉表头包含 `原申报价格` 和 `新申报价格`。
- 价格表头币种可能是 `USD` 或 `CNY/RMB`。

页面检查应读取控件实际值，不能只判断页面文字。特别是每页数量通常是只读输入框，页面文本不一定出现“每页 50”。

## 已验证页面能力

- 设置每页 50 条。
- 筛选「待卖家确认」。
- 输入 SKC 并查询。
- 全选商品。
- 打开「查看并确认申报价格」抽屉。
- 滚动虚拟表格读取全部站点和 SKU。
- 重新调整报价、填写原因和填报新价格。
- 页面表头为 CNY 时读取和提交 CNY。
- 页面表头为 USD 时读取和提交 USD。
- 100 个 SKC、多站点读取和正式提交曾完成。
- #7946 窗口已加载扩展并完成 USD 页面预览测试。

## 标签锁定

- 侧边栏锁定目标标签页 ID。
- 检查、开始和暂停通过锁定 ID 发送消息。
- 切换到其他 Temu 后台标签后，原任务目标和暂停目标不变。
- 锁定标签关闭或离开目标路由时，扩展清除锁定。

## 登录失败

若出现 `/auth/authentication` 重定向：

- 扩展只提示用户重新登录。
- 不尝试自动填写账号、密码或验证码。
- 不绕过安全验证。
- 登录完成后回到目标路由，再重新检查页面。

## 页面结构调整

以下情况应 fail closed：

- 找不到分页、状态或批量管理控件。
- 查询结果与请求 SKC 无法完整归类。
- 价格抽屉组数不一致。
- 抽屉混入旧 SKC。
- 价格或币种无法解析。
- 提交前找不到唯一确认按钮。
