# TEMU 商品图片自动编辑助手 v0.10.14（Chrome 扩展 / 比特浏览器适用）

在 TEMU 商家中心按 SKC 或 SPU 批量新增色值并自动补图，最后自动提交。

> 第一次使用请先阅读：[初次使用公告](../docs/初次使用公告.md)

v0.8.1 起面板改为三段式工作台：

- **任务**：导入清单与素材、查看预检结果。
- **参数**：商品、平台属性、价格与 SKU 参数分组编辑。
- **记录**：实时日志、截图和诊断。

顶部显示真实进度、当前阶段和单任务保护状态；开始、暂停、停止固定在底部。

v0.9.1–v0.9.2 多货号任务：
- 每个货号建立独立任务卡，各自使用一份 Excel 和图片文件夹。
- “保存准备”只做导入、图片标准化和参数校验，不进入 TEMU 编辑页。
- 点击“开始队列”后，按任务列表顺序自动串行执行。
- 同一浏览器窗口只允许一个任务运行；不同窗口可并行。
- 同一货号任务同时只能在一个窗口运行。

v0.9.4 运行统计与失败重试：
- 顶部按 SKC 显示任务总数、成功、失败、超时跳过和待处理。
- 每个任务卡显示成功、失败、超时数量，最终状态分为全部成功、部分成功、失败。
- `重试失败（N）` 只重跑失败、待确认和超时 SKC，不会重复处理成功项。
- 支持跨货号任务自动切换的重试队列。
- SKC 记录尝试次数和最近原因；超过 3 次仅警告。
- 准备类问题不自动重试，必须补齐资料并重新准备。
- 超时或最终失败时回滚本轮主图占用。

v0.9.5 皮肤扩充：
- 新增玫瑰豆沙、靛蓝、橄榄绿、泻湖青、薰衣草、酒红 6 套预设。
- 当前共 18 套皮肤，色块自动换行。
- 自定义主色、深色模式、透明度和位置记忆继续可用。

v0.9.6 渐变与纹理主题：

- 当前共 24 套皮肤，色块改用渐变预览。
- 继续保持 Shadow DOM 隔离，不影响 TEMU 页面本身。

v0.9.7 皮肤持久化修复：
- 修复页面刷新或站内跳转后皮肤恢复默认的问题。

## 一、安装（3 步）

1. 打开比特浏览器，进入**该窗口的扩展管理页**（地址栏输入 `chrome://extensions`，或在窗口菜单里进入"扩展管理"）。
2. 打开右上角 **开发者模式**，点 **加载已解压的扩展程序**，选择本目录：
   `temu-operations/auto-recolor/extension`
3. 回到目标窗口，**刷新一次** TEMU 页面（扩展需要在页面加载时注入）。
   页面右下角出现蓝色的「TEMU 图片自动编辑助手」面板即安装成功。

> 扩展只在 `https://agentseller.temu.com/*` 生效。
> 如果右下角没有面板，先确认扩展已启用，再刷新页面；仍无面板请看 `chrome://extensions` 里该扩展的"错误"信息。

## 二、使用（按顺序）

1. 打开 `https://agentseller.temu.com/goods/list`（商品列表）。
2. 点击“＋ 新建货号任务”，会自动进入该任务的参数与准备页面，在顶部“货号”输入框填写唯一货号。一个货号对应一个任务。
3. 在当前任务中依次操作：
   - **导入商品清单**：先选择“SKC 清单”或“SPU 清单”，再选择 Excel/CSV/TXT。表头含 `SKC ID` 或 `SPU ID` 时会自动识别；两者都有时按界面选择。
   - Excel 的“状态”列会持续记录查询中、上传成功、提交中、提交成功或失败原因；任务结束后自动下载回写副本。
   - **导入主图文件夹**：选择主图目录。插件按文件自然顺序只为本轮待处理商品选取实际需要的图片，并建立固定计划。
   - **导入背面图文件夹**：插件固定选取配置的 X 张背面图，所有商品和色值复用。
   - 先完成全部色值名称和货号，再把当前商品全部计划主图和背面图一次性上传、一次裁剪，之后逐色值按计划选择。
   - 设置 **新色值货号**（如 `DWRG`，想自动编号写 `DWRG{i}` → `DWRG2/DWRG3…`）、**新增色值数量**（1–7）、**每个色值的背面图张数**、**图片裁剪尺寸**。
   - 设置 **敏感属性 / 体积（长×次长×最短，cm）/ 重量（g）**：新增色值的每个尺码都会统一填这些值（留空则照抄第一个色值）。
   - **申报价格**默认逐尺码、逐站点沿用「混合色」已核价的价格；「备用申报价」只在混合色某个站点为空时使用。
   - **库存**默认 500，**SKU分类**默认单品，**SKU货号**必填（默认 DWRG）。
   - **严格自检**默认开启：色值未登记、价格未沿用、敏感属性/体积/重量或 SKU 信息不完整时不会提交。
   - 需要先试跑时勾选 **安全演练（只做不提交）**。
   - 设置 **卡死无进展超时（分钟）**，默认 10 分钟；只有连续无进展才回写“卡死超时”并进入下一条。
   - 面板中间那行"预估"会实时告诉你：本次处理几个商品、要几张主图、主图够不够。红字出现就先别开始。
4. 当前货号资料和参数确认后，点击资料区下方的橙色 **保存准备** 按钮；准备完成后按钮会变为绿色。重复上述步骤准备其他货号。
5. 全部任务准备完成后，点击 **开始队列**。插件会按任务列表顺序自动执行：按任务类型查询 SKC 或 SPU → 完成全部色值和货号 → 批量上传本商品计划图片 → 逐色值对应选择 → 提交 → 下一个商品。
6. 中途可以 **暂停 / 停止**；失败会自动重做 1 次，仍失败则暂停并给出原因。
7. 每个货号任务完成后自动生成自己的状态 Excel，并自动进入下一个准备完成的任务。
8. 有失败或超时项时，底部会显示 `重试失败（N）`；点击后只补跑未成功项，并按任务顺序自动切换。

### 多店铺 / 多窗口
- 面板右上角会自动显示**当前店铺名**（例：`HYPELYRA`）。
- 点 **⚙ 设置 → 窗口备注** 可以写"7512-店铺A"之类，标题栏会同时显示备注和店铺名，多个窗口并排时不会搞混。
- 每个比特浏览器配置拥有自己的任务列表；不同窗口可以并行执行不同货号任务
  （图片文件夹因为浏览器安全限制，需要在每台电脑上重新选一次）。
- 同一个窗口里只允许一个任务标签页运行；同一货号任务也不能跨窗口重复运行。

### 换皮肤
点 **⚙ 设置 → 外观**：24 套预设皮肤，包括 18 套纯色/深色主题和 6 套渐变纹理主题（极光流彩、落日霞光、青瓷雨纹、深海星云、奶油格纹、雾粉樱云），并保留自定义主色、深色模式、面板透明度。选择会自动保存，刷新或站内跳转后保持不变。
面板可以拖动标题栏或没有交互控件的空白区域，位置和折叠状态会自动记住；拖动右下角可以调整宽高。按钮、输入框、日志和设置层不会误触发拖动。右上角“×”可关闭成悬浮按钮，点击悬浮按钮恢复。皮肤只影响插件面板，不会影响 TEMU 页面。

### 断点续跑
任务状态、图片、日志都存在页面同源的 IndexedDB 里。若浏览器崩溃或你手动刷新，重新打开列表页后会自动接着跑（面板会显示"自动续跑"）。

## 三、行为说明（与 TEMU 页面的约定）

| 项目 | 行为 |
|---|---|
| 原色值行 | **永不修改**（被平台锁定的行保持原样），只新增 `Mixed Color2 … n+1` |
| 正面图 | 每个新增色值 1 张，准备时固定绑定，重试沿用原计划 |
| 背面图 | 每个新增色值 X 张；**只在素材库缺失时上传一次**，之后按素材名从库里选中复用 |
| 裁剪 | 所有图片统一裁成 **1350×1800** |
| 提交 | 全部色值完成后自动提交；提交前会自检（每行 ≥3 张图、色值名、货号） |
| 重复上传提示 | 自动关闭并改为从素材库选取 |
| 敏感属性与体积重量 | 新增色值后平台要求的这一节，插件会**照抄第一个色值（混合色）**的敏感属性、体积、重量（按尺码对应），并在提交前自检 |
| 申报价格 | 按「尺码 + 站点」逐项沿用混合色价格，不会统一改成 300，避免触发涨价校验 |
| 色值登记 | 自定义色值写入后会自动失焦，确认平台占位文字已变为该色值；仅输入框显示文字不算成功 |
| 商品批量上传 | 每个商品的全部计划主图和背面图一次上传、一次裁剪、逐张验证 |
| 色值对应 | 每个色值从素材库选择自己计划的主图和固定背面图 |
| 批量属性 | 使用平台原生“批量填写”：先选新增 SKU 范围，再一次写入敏感属性、体积、重量 |
| SKU 批量 | 使用平台原生“批量填写”一次设置新增 SKU 的「单品、1件」和 SKU 分类 |
| 提交确认 | 自动处理价格风险确认；商品信息待确认无法闭环时立即暂停 |
| 完成判定 | 页面成功提示或列表“提交成功/信息修改中/修改成功/审核中/已提交/审核通过”均确认成功 |
| 图片自检 | 结合本轮已确认写入数量和重新挂载后的实际 DOM，避免虚拟化导致 0 张误判 |
| 双层任务锁 | 同一窗口只允许一个任务；同货号任务跨窗口也不可重复执行 |
| 异常回滚 | 超时、自动重做、最终失败或提交未确认时回滚本轮主图使用记录 |
| Excel 回写 | 按 SKC/SPU 回写状态，不覆盖原文件；任务结束自动下载带时间戳的副本，也可手动点“下载回写 Excel” |
| 运行汇总 | Excel 新增“运行汇总”工作表，包含成功/失败/超时/待处理数量、尝试次数和最近原因 |
| 卡死保护 | 连续无有效进展达到设定时间时，回滚图片、刷新列表并自动继续下一个商品 |
| 图片合规拦截 | 所有等待步骤中检测牛皮癣、LOGO等图片品质弹窗，立即取消并跳过当前商品 |
| 安全导航 | 插件内部跳转统一由调试协议执行，遇到“离开此网站”确认会自动按既定流程继续 |
| 商品信息确认 | 自动进入 `/newon/product-select`，点行级“去确认”和抽屉底部最终确认，再回列表校验 |
| 图片标准化 | 导入时统一居中裁剪为 1350×1800 JPEG，质量自动降级到 1.8MB 内；不修改原文件 |
| 主图不复用 | 按文件名记录已用过的主图，跨商品/重启续跑都不会重复使用 |

> 说明：色值名称框只接受"真实按键"，插件通过扩展调试接口发送真实文本输入（首次使用时 Chrome 顶部可能短暂出现"正在调试此浏览器"提示，插入完成即自动关闭）。

## 五、常见问题

**Q：面板没有出现？**
确认扩展已启用并刷新页面；确认当前域名是 `agentseller.temu.com`（不是 `-eu` 站点）。

**Q：提示"找不到某个元素"？**
TEMU 页面改版导致。把日志导出发我，我按新结构更新选择器（选择器都集中在 `page/main.js` 顶部与各步骤函数里）。

**Q：提示"主图不足"？**
要求 张数 ≥ `商品数 × n`，不足时不会执行任何页面动作。

**Q：备份/恢复配置？**
用 **导出配置** 存成 json；换电脑时点 **导入配置** 即可（图片文件夹需重新选择一次）。

**Q：同事那边出问题怎么排查？**
让同事点 **⚙ 设置 → 导出诊断包**，会生成一个 txt（版本、页面 URL、店铺名、参数、进度、最近 200 行日志）+ 一张当前页面截图，发给你转给我即可。

**Q：怎么更新到新版本？**
把新的 `extension` 文件夹覆盖到原位置，然后到扩展管理页点一下该扩展的"重新加载"，再刷新 TEMU 页面。
