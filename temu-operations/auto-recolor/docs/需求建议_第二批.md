# 第二批需求 —— 修改建议（历史记录）

> 当前版本为 v0.10.11。最新使用方式以 [初次使用公告.md](./初次使用公告.md) 为准；本文保留早期需求讨论。当前已支持任务列表与详情分屏、面板边缘/四角自由伸缩、卡死硬跳过、SKC/SPU 双清单、下架 SKC ID 标准模板、精确图片计划、每商品批量上传、全局图片合规拦截、提交结果待确认、虚拟化图片自检和 24 套主题。

针对你提的 4 点，逐条给出我的建议方案、备选方案和需要你决定的地方。

## 1. 参数命名改成人人看得懂

### 现状
面板上写的是 `货号A` / `n` / `X` / `裁剪` / `自动提交` / `演练(不提交)`，新人第一次看到不知道填什么。

### 建议命名（中文为主，英文缩写只作为括号备注）

| 现在 | 建议改成 | 提示文字（鼠标悬停 / 名字下方小字） |
|---|---|---|
| 货号A | **新色值货号** | 固定填 `DWRG`；想按顺序编号就写 `DWRG{i}`，会自动变成 `DWRG2`、`DWRG3`… |
| n | **新增色值数量** | 每个商品要新增几个颜色，1–7 个。新增后色值总数为「原有 + 这个数」 |
| X | **每个色值的背面图张数** | 从背面图文件夹里取几张，这 X 张会被所有新增色值复用 |
| 裁剪 1350×1800 | **图片裁剪尺寸（宽 × 高）** | 上传后统一按这个尺寸裁剪，默认 1350×1800（平台要求的 3:4） |
| 自动提交 | **处理完自动提交** | 不勾选则每个商品跑完会停下，等你点提交 |
| 演练(不提交) | **安全演练（只做不提交）** | 勾上后完整走一遍流程但最后不提交，用来验收 |

### 另外建议补 3 个"看得懂"的辅助信息
1. **任务预估行**：`本次将处理 2 个商品，共新增 8 个色值；需要主图 8 张（已导入 31 张），背面图 2 张/色值`。
2. **参数文字校验**：数量填超范围、主图不够时，直接在面板上红字提示，不等到开始才报错。
3. **首次使用向导**（3 步小浮层）：① 导入 SKC 清单 ② 导入两个图片文件夹 ③ 设置货号与数量 → 点开始。第一次打开面板时自动显示，点"我知道了"后不再出现。

### 需要你拍板
- **D1**：上面这套命名是否照用？（也可以你指定更土更直白的叫法，比如"一个商品加几个颜色"）
- **D2**：要不要做"首次使用向导 + 参数实时校验"？（我建议做，成本很小）

## 2. 一台电脑多个店铺、多个窗口同时跑

### 现状与原理
- 插件目前把状态存在**页面同源 IndexedDB**里，而比特浏览器每个窗口是独立 profile（独立存储），
  所以**多个窗口天然互不干扰**，可以同时跑不同店铺。
- 同一个窗口内已经加了"任务标签页标记"（URL 带 `#temu-image-bot`），用户自己开的标签页不会误启动任务。

### 建议做的 3 件事

**① 窗口身份显示（防止搞错店铺）**
面板顶部显示当前店铺/账号名（从页面右上角读取，例如 `HYPELYRA`）+ 窗口序号（如 `7512`）。
日志和报表里也带上店铺名，结束后一眼能看出"哪个店铺跑了什么"。

**② 每个窗口一套独立配置档案，并支持"导出/导入配置"**
- 每个窗口自己保存：货号规则、色值数量、背面图张数、裁剪尺寸、皮肤、SKC 清单。
- 面板上加 **导出配置（.json）** 和 **导入配置**：换窗口、换同事电脑时，一个文件就把参数搬过去，
  不用重新输入（图片文件夹因为浏览器安全限制必须在新电脑上重新选一次）。

**③ 多开时的互斥与提示**
- 同一窗口内如果已有标签页在跑任务，新标签页的面板会提示"任务在另一个标签页运行中"，并给一个"在本页接管"按钮。
- 面板顶部显示一个状态灯：`空闲 / 运行中 / 已完成 / 出错`，多窗口并排时一眼可辨。

### 需要你拍板
- **D3**：是否按上面 3 件做？（我建议全做，多店铺场景下"导出/导入配置"最省事）
- **D4**：面板是否要显示店铺名？（读取页面右上角的店铺名，如果读不到就显示"未识别"）

## 3. 要发给同事用

### 建议交付方式
1. **一个压缩包**：`TEMU图片助手-v0.2.0.zip`（解压后是 `extension` 文件夹）。
2. **一页图文安装说明**（`安装说明.md` + 3 张截图）：开开发者模式 → 加载已解压 → 刷新页面。
3. **首次使用向导**（同 D2）让同事不用你口头教。
4. **一键诊断**：面板上加「导出诊断包」按钮，导出内容包括：插件版本、当前页面 URL、店铺名、参数、任务进度、最近 200 行日志。
   同事出问题时把文件发你，你转给我就能定位，不用远程。
5. **版本号显示 + 更新方式**：面板底部显示 `v0.2.0`；更新时把文件夹覆盖后点一下"重新加载"即可。

### 隐私与安全说明（建议写进说明文档）
- 插件只在你打开的 TEMU 商家页面里运行，**不联网、不上传任何数据**（图片和日志都只在本机）。
- 只在 `agentseller.temu.com` 生效，不读取其它网站。
- 图片文件夹由使用者在本地选择，浏览器不允许插件记录你电脑上的绝对路径。

### 需要你拍板
- **D5**：交付形式就按"zip + 图文说明 + 诊断包"来？还是你希望我做成 `.crx` 安装包（比特浏览器不一定支持双击安装，可能需要额外步骤）？
- **D6**：要不要在面板里放一个「检查更新」的手动按钮（只显示当前版本和更新说明，不自动联网）？

## 4. 个性化换皮肤

### 建议范围（面板皮肤，不影响 TEMU 页面本身）
| 功能 | 说明 |
|---|---|
| **预设皮肤 6 套** | 经典蓝（默认）、星空紫、森林绿、暖橙、少女粉、暗夜黑 |
| **自定义主色** | 一个取色器，选什么颜色就用什么颜色做按钮和标题栏，自动配深浅色 |
| **深色模式** | 一键切换 / 跟随系统 |
| **面板位置与折叠状态记忆** | 可以拖到任意角落，下次打开还在原位；折叠后只留一个小圆标 |
| **透明度与圆角** | 一个滑杆（0.85–1.0），让面板别挡住商品图 |
| **（可选）背景图** | 允许上传一张图当面板背景（默认关闭） |

实现上：面板本身是用 Shadow DOM 隔离的，皮肤只改插件自己的样式，**不会影响 TEMU 页面的显示**；
皮肤设置按窗口保存，也可以跟着"导出配置"一起带走。

### 需要你拍板
- **D7**：皮肤就按"6 套预设 + 自定义主色 + 深色模式 + 位置记忆"做？要不要加"背景图自定义"？
- **D8**：默认皮肤用哪个？（我建议默认"经典蓝"，最不容易看错状态色）

## 附：这次改动的工作量与风险

| 项 | 影响范围 | 风险 |
|---|---|---|
| 参数改名 + 提示 + 预估行 + 向导 | 仅面板 UI + 校验逻辑 | 低（不动自动化流程） |
| 窗口身份 + 配置导入导出 + 互斥提示 | 面板 + 状态存储 | 低 |
| 诊断包导出 | 面板 + 日志 | 低 |
| 换皮肤 | 仅面板样式 | 低（Shadow DOM 隔离） |

**结论**：这 4 条都不碰已经验证过的自动化主流程（选择器、上传、裁剪、提交），属于"外壳"改造，可以在你现有的演练结果基础上安全迭代。
