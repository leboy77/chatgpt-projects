# TEMU 图片自动编辑助手 v0.10.11 初次使用公告

## 一、先了解这三件事

1. **一个货号就是一个任务。**  
   每个任务独立使用自己的商品清单（SKC 或 SPU）、主图文件夹、背面图文件夹、参数和状态表，不要混用。

2. **先准备，后执行。**  
   导入资料和设置参数后，点击“保存准备”。“保存准备”不会进入 TEMU 编辑页。
   全部任务准备完成后，再点击“开始队列”，插件会按任务列表顺序自动依次执行。

3. **同一窗口只运行一个任务。**  
   不同比特浏览器窗口可以并行处理不同货号；同一窗口会阻止第二个任务同时启动。
   同一货号任务也不能在两个窗口重复运行。

---

## 二、安装

1. 解压 `TEMU图片助手v0.10.11.zip`。
2. 在比特浏览器打开 `chrome://extensions`。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后的目录。
5. 回到 TEMU 页面刷新一次，右下角出现“TEMU 图片工作台”即安装成功。

升级时覆盖原扩展目录，然后在扩展管理页点击“重新加载”，再刷新 TEMU 页面。

## 三、第一次使用

### 1. 新建货号任务

点击“＋ 新建货号任务”，填写一个唯一货号。

新建任务后会进入该任务自己的“参数与任务准备”页面。主页面只显示任务列表、汇总和开始/停止按钮，不再显示参数。

点击任意任务卡可以重新进入对应任务的参数与准备页面。

货号已经移到任务页顶部，并带有“必填”标记。输入货号会立即同步任务卡名称和默认 SKU 货号。

建议：

- 货号具有业务唯一性，例如 `DWRG001`。
- SKU货号默认使用同一货号；也可按业务规则单独修改。
- 一个任务只处理一个货号的商品清单，类型可以是 SKC 或 SPU。

### 2. 导入任务资料

该货号必须使用自己的：

- 商品清单 Excel：可使用 `SKC ID` 或 `SPU ID`，建议同时包含 `状态` 列。
- 主图文件夹。
- 背面图文件夹。

在“商品清单类型”中选择 SKC 或 SPU。导入时插件会优先检查 Excel 表头：

- 只有 `SKC ID`：自动按 SKC 查询；
- 只有 `SPU ID`：自动按 SPU 查询；
- 两种列都有：按你在界面上选择的类型执行。

切换清单类型会清空当前任务中的旧清单和状态，需要重新导入对应 Excel，防止把 SPU 错当 SKC。

图片导入后会自动：

- 只挑选本轮实际需要的图片；
- 居中裁剪为 1350×1800；
- 铺白底；
- 转为 JPEG；
- 压缩到约 1.8MB 以内；
- 不修改原文件夹。

每个待处理商品会固定绑定 n 张主图，并固定复用 X 张背面图。失败重试继续使用原计划，不会错位或消耗后面商品的主图。

### 3. 设置参数

常用参数：

| 参数 | 默认/建议 |
|---|---|
| 新增色值数量 n | 4，可设置 1–7 |
| 每个色值背面图数量 X | 2 |
| 敏感属性 | 否 |
| 体积 | 30×20×1 cm |
| 重量 | 500 g |
| 库存 | 500 |
| SKU分类 | 单品 |
| SKU货号 | 与本次货号一致，必填 |
| 卡死无进展超时 | 10 分钟 |
| 严格自检 | 开启 |

申报价格会按“尺码 + 站点”沿用混合色价格；备用申报价只在混合色对应站点为空时使用。

卡死超时只在连续没有有效进展时触发。正常上传图片、裁剪、填写 SKU 或处理平台弹窗会重新计时，不会因为单个商品总处理时间较长而被误跳过。

### 4. 保存准备

点击“保存准备”。

保存准备按钮位于任务资料下方：

- 橙色：资料未齐或等待保存；
- 绿色：准备完成，可以开始队列。

按钮上方会显示货号、商品清单、主图、背面图四项检查结果。

准备阶段只做：

- Excel 解析；
- 图片标准化；
- 图片数量校验；
- 参数校验。

准备阶段不会进入 TEMU 商品编辑页面。

### 5. 准备多个货号

继续点击“＋ 新建货号任务”，为其他货号重复导入资料和保存准备。

任务列表会显示：

- 草稿；
- 准备完成；
- 运行中；
- 已暂停；
- 全部成功；
- 部分成功；
- 失败。

顶部统计显示“任务总数、成功商品、失败商品、超时跳过、待处理”；每个任务卡也会显示自己的成功、失败和超时数量。

### 6. 开始队列

全部任务准备完成后，点击底部的“开始队列”。

插件会按任务列表顺序自动执行：

1. 按任务类型查询 SKC 或 SPU；
2. 打开编辑页；
3. 先创建全部新增色值和货号；
4. 每个商品先一次性上传该商品的全部计划主图和背面图，裁剪一次并逐张验证入库；
5. 每个色值再从素材中心按计划选择自己对应的主图和固定背面图；
6. 批量填写敏感属性、体积和重量；
7. 填写 SKU 价格、分类、库存和货号；
8. 提交并完成商品信息确认；
9. 回列表校验；
10. 生成该任务的状态 Excel；
11. 自动进入下一个准备完成的任务。

### 7. 失败后只补跑失败项

任务暂停后，如果底部按钮显示 `重试失败（N）`，点击后插件会：

- 只收集失败、待确认和卡死超时的商品；
- 自动跳过已经成功的商品；
- 跨多个货号任务建立重试队列，并按任务列表顺序自动切换；
- 卡死超时或最终失败时释放当前商品本轮占用的主图，重试可继续使用这些图片。

主图不足、目录未导入、商品清单为空等准备问题不会进入自动重试。补齐资料后，先点击该任务的“保存准备”，再开始队列。

## 四、图片规则

- 正面图每个新增色值使用 1 张，按文件夹顺序取用。
- 正面图不重复使用。
- 背面图首次上传入库，后续色值从素材库复用。
- 所有正面图、背面图统一输出为 1350×1800 JPEG。
- 单图超过约 2MB 时自动压缩，不需要手工处理 PNG。

---

## 五、状态 Excel

插件会在原 Excel 的状态列写入：

- 查询中；
- 已找到商品；
- 上传成功；
- 提交中；
- 提交成功；
- 待确认商品信息；
- 重试中；
- 超时跳过；
- 失败原因。

插件不会覆盖原文件，而是下载带时间戳的新副本，例如：

`skc ID-状态-20261017T080409.xlsx`

也可以在“任务”页手动点击“下载回写 Excel”。

Excel 还会增加一个“运行汇总”工作表，记录：

- 当前任务与整个队列的成功、失败、超时和待处理数量；
- 每个 SKC/SPU 的最终状态、尝试次数、最近失败原因和更新时间。

## 六、页面锁定与多开

- 点击“开始队列”不会切换到其他已有任务页。
- 同一个任务始终在自己的任务标签页内跳转。
- 同一浏览器窗口只允许一个任务执行。
- 不同浏览器窗口可以并行处理不同货号。
- 同一货号任务不能跨窗口重复运行。
- 平台打开的商品信息确认新标签会被当前任务页接管，多余标签自动关闭。

### 面板外观

设置中提供 24 套主题。除了纯色主题，还新增 6 套艺术主题：

- 极光流彩：青绿到蓝紫渐变和柔光；
- 落日霞光：酒红、珊瑚和暖橙光晕；
- 青瓷雨纹：青瓷绿渐变与斜向细纹；
- 深海星云：深色背景、蓝紫与青色星云光；
- 奶油格纹：奶油底色和浅棕细格；
- 雾粉樱云：雾粉渐变和淡紫圆点纹理。

所有色块现在使用渐变预览。也可以继续自定义主色、开启深色模式并调整透明度。

皮肤、深色模式、透明度和面板位置会保存在当前浏览器窗口中。刷新 TEMU 页面、在站内切换页面或重新加载扩展后，会恢复上一次的选择，不再自动回到默认主题。

面板可以拖动标题栏或没有按钮/输入框的空白区域来移动。按钮、输入框、日志区和设置面板不会误触发拖动。

标题栏右上角的“×”可以把面板收成一个小悬浮按钮；点击悬浮按钮可重新打开，关闭状态会保存。

面板右下角现在可以拖动调整宽高。拉大后任务、参数和日志区域会同步扩展；自定义尺寸会保存，刷新或切换任务后继续沿用。

## 七、提交与确认

插件会自动处理：

1. “当前存在异常，确认录入”；
2. “没问题继续提交”；
3. “存在商品信息待确认”；
4. 上新生命周期页的行级“去确认”；
5. 商品信息确认抽屉底部的“确认商品信息并同意以上全部内容”。

必须满足以下任一条件才进入下一个商品：

- 平台提示提交成功；
- 商品列表显示“信息修改中”；
- 商品列表显示“修改成功”。

未确认成功时会暂停，不会假装成功继续执行。

## 八、异常处理

- 连续超过设定时间没有任何有效进展：自动写入“卡死超时”，刷新回列表并继续下一个商品。
- 主图不足：准备阶段阻止开始。
- 图片过大或损坏：准备阶段报出具体文件名。
- 提交未确认：本轮主图使用记录回滚，任务暂停。
- 自动重做 1 次仍失败：任务暂停，并计入失败商品。
- 同一商品累计尝试超过 3 次：写警告日志，但不会禁止继续手动重试。
- 页面卡住：先等待超时跳过；仍无法继续时点击暂停并导出日志和诊断包。
- 卡死超时：连续达到设定分钟数没有任何有效进展时，自动跳过本轮并处理下一个商品。
- 提交后卡死：标记“提交状态待确认”，继续本轮下一个商品，不立即自动重提，避免重复提交。
- 图片品质不合规：在所有等待步骤中优先检测平台弹窗，自动选择“取消”，不选择“删除后继续上传”；当前商品记录为图片合规失败并跳到下一个商品。替换同名原图并重新准备后可再次执行。
- 提交后页面没有明确提示：先在商品列表查询真实状态，不自动重复提交。列表显示“提交成功、信息修改中、修改成功、审核中、已提交、审核通过”时均判定成功。
- 图片已经上传但仍显示“轮播图 0 张”：插件会结合本轮图片写入确认记录，并在自检前重新滚动等待图片区域渲染，避免把平台虚拟化造成的 0 张误判为缺图。

## 九、开始前检查清单

- [ ] 每个货号都建立了独立任务。
- [ ] 每个任务都有自己的 Excel、主图目录和背面图目录。
- [ ] Excel 包含 `skc ID` 和 `状态` 列。
- [ ] 主图数量不少于商品数 × n。
- [ ] 货号唯一。
- [ ] 参数检查通过。
- [ ] 任务状态显示“准备完成”。
- [ ] 当前窗口没有其他任务正在运行。
- [ ] 最后点击“开始队列”。

## 十、遇到问题怎么反馈

请提供：

1. 当前货号；
2. 当前 SKC 或 SPU；
3. 面板显示的状态和错误；
4. “导出日志”；
5. “导出诊断包”；
6. 出问题时的截图。

不要只描述“失败了”，日志和诊断包能直接定位到具体步骤。
