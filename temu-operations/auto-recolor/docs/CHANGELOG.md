# CHANGELOG

本文件只记录**版本级变化**。详细根因、现场日志和实现过程见 [archive/技术方案.md](./archive/技术方案.md)。

> 维护规则：每次发版必须在顶部增加新版本；`tools/build_release.py` 会校验当前版本号是否出现在本文件。

---

## v0.10.15 — 2026-11-12

### 新增

- 轮播图维护：按商品 ID 定向删除第 N 张轮播图，可选新增图片。
- 多色值：每个色值组执行同一删除顺序，并可逐组新增。
- 批量 ID：支持多行/逗号分隔，支持 xlsx/csv/txt 导入、去重、按顺序执行。
- 批量结果：记录每个 ID 的色值组数和最终每组轮播图数量。
- 跨页续跑：图片更新任务页和图片更新详情页之间自动续跑。

### 修复

- 缩小按钮现在隐藏整个插件框，只保留右下角悬浮按钮；点击悬浮按钮恢复。
- 修复部分窗口图片更新页调试器点击受限的问题：轮播图流程改用 `element.click()`。

### 验证

- 45687392555：删除第 5 张 + 新增 1 张，最终 5 张。
- 9542570366：4 个色值组，删除第 5 张 + 新增 1 张，最终 7/5/5/5。
- 批量顺序：9542570366 → 45687392555，最终“全部完成 2/2（安全演练，未提交）”。
