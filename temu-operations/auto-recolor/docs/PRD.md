## 1. 产品定位

TEMU 图片助手是一个运行在 Chrome / 比特浏览器中的 MV3 扩展，面向 TEMU 半托管/全托管卖家，把重复的商品图片维护工作自动化：

1. **商品图片自动编辑**：按 SKC/SPU 清单批量新增色值，填写 SKU 信息，上传正面图和背面图，裁剪、选中、确认并提交。
2. **轮播图维护**：按商品 ID 批量定向删除指定顺序的轮播图，可选新增图片，并逐色值处理。
3. **任务与状态管理**：多货号任务、多窗口并行、Excel 状态回写、失败重试、超时跳过、日志与诊断。

产品目标是减少重复点击和人工核对，同时保留“安全演练”和“提交前自检”，避免误提交。

## 2. 目标用户与使用场景

### 2.1 目标用户

- 需要给已出单商品批量复色的 TEMU 运营。
- 需要给多个店铺/多个浏览器窗口并行处理任务的操作员。
- 需要按商品 ID 批量维护轮播图的运营或图片维护人员。

### 2.2 典型场景

- 一个货号对应一份 SKC/SPU 清单、一套主图目录、一套背面图目录和一组参数。
- 运营先准备多个货号任务，再点一次“开始队列”，插件按任务顺序执行。
- 运营手里有一批商品 ID，需要删除每个商品每个色值的第 N 张轮播图；如需要，再在每个色值补一张新图。

## 3. 目标与边界

### 3.1 本期目标

- 商品列表页按 SKC/SPU 查询并进入编辑页。
- 新增 1–7 个色值（Mixed Color2–Mixed Color8），填写 SKU 货号。
- 每个色值上传 1 张正面图 + X 张背面图；统一裁剪为 1350×1800。
- 自动填写敏感属性、体积、重量、申报价格、库存、SKU 分类和 SKU 货号。
- 自动提交、状态回写、失败重试、卡死跳过、提交结果待确认。
- 按商品 ID 批量定向删除轮播图，可选新增图片；支持多色值和批量顺序执行。
- 多窗口、多店铺、多任务并发隔离。

### 3.2 不在本期范围

- 自动登录、验证码、短信验证或绕过平台风控。
- 修改平台锁定的原色值行。
- 绕过平台图片合规校验或使用不合规图片。
- 自动下架商品（当前只提供“多色 SKC ID”标准 Excel 模板下载）。
- 云端同步任务或图片；跨电脑需要重新选择图片文件夹。

## 4. 术语与参数

| 术语 | 含义 |
| --- | --- |
| SKC | TEMU 商品色值/款式 ID |
| SPU | TEMU 商品 ID |
| 货号 | 商家内部商品编号，同时作为任务名称和 SKU 货号默认值 |
| n | 每个商品新增的色值数量，1–7 |
| X | 每个色值复用的背面图张数，1–10 |
| 混合色 | 商品原有的第一个色值；新增色值从 Mixed Color2 开始 |
| 安全演练 | 完成操作但不点击最终提交 |
| 轮播图维护 | 按商品 ID 定向删除/新增轮播图的功能 |

### 4.1 商品图片自动编辑参数

| 参数 | 默认值 | 范围/说明 |
| --- | --- | --- |
| 货号 | DWRG | 必填；一个货号对应一个任务 |
| 清单类型 | SKC | SKC / SPU |
| 新增色值数量 n | 4 | 1–7 |
| 每个色值背面图 X | 2 | 1–10 |
| 裁剪尺寸 | 1350×1800 | 宽×高，统一 JPEG |
| 自动提交 | 开启 | 关闭时只处理不提交 |
| 安全演练 | 关闭 | 开启时强制不提交 |
| 敏感属性 | 否 | 是/否 |
| 体积（cm） | 30×20×1 | 长×次长×最短 |
| 重量（g） | 500 | 统一填入新增尺码 |
| 备用申报价 | 300 | 混合色对应站点价格为空时才使用 |
| 库存 | 500 | 留空也按 500 |
| SKU 分类 | 单品 | 单品/同款多件装/混合套装 |
| SKU 货号 | DWRG | 必填；固定或加随机后缀 |
| 严格自检 | 开启 | 缺字段不提交 |
| 半自动模式 | 关闭 | 敏感属性/体积重量+提交交人工 |
| 卡死无进展超时 | 10 分钟 | 3–120 分钟 |

### 4.2 轮播图维护参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 商品 ID | 空 | 支持多个 ID；SPU/SKC/SKC 货号均可 |
| 删除第几张 | 1 | 1–10；每个色值删同一顺序 |
| 同时新增图片 | 关闭 | 开启后可多选本地图片 |
| 安全演练 | 开启 | 开启时不提交；正式提交前取消 |
| 上传裁剪 | 1350×1800 | 轮播图维护固定使用 |

## 7. 商品图片自动编辑

### 7.1 任务准备

1. 在商品列表页打开工作台。
2. 新建货号任务，填写唯一货号。
3. 选择 SKC 或 SPU 清单，导入 Excel/CSV/TXT。
4. 导入主图文件夹和背面图文件夹。
5. 设置参数，点击“保存准备”。
6. 重复准备其他货号，最后点击“开始队列”。

一个任务只使用自己的清单、图片和参数；不同任务不能混用。

### 7.2 导入清单

- Excel 表头支持 `SKC ID`、`SPU ID`、`多色 SKC ID`、`商品 ID`、`货号` 等。
- 可选 `状态` 列；插件会写回查询中、上传成功、提交中、提交成功、失败原因、卡死超时等。
- 没有表头时，自动提取 6–20 位数字 ID。
- 导入后建立固定图片计划：第 1 个商品用第 1 张主图，第 2 个用第 2 张，依序不复用。

### 7.3 查询与进入编辑

1. 在商品列表页按当前 ID 查询。
2. 找到结果行的 SPU。
3. 打开“编辑 → 修改商品其他信息”。
4. 进入商品编辑页。

### 7.4 新增色值与 SKU 货号

- 原“混合色”行保持不动；平台锁定后只新增色值。
- 依次新增 Mixed Color2 到 Mixed Color(n+1)。
- 每个新增色值填写 SKU 货号：
  - 固定：全部为 DWRG（或用户填写值）。
  - 随机：DWRG-s-随机3位。
- 新色值登记为有效 SKC 颜色后，才允许提交。

### 7.5 图片处理

- 正面图：每个新增色值 1 张，按计划顺序取用，不重复。
- 背面图：每个色值 X 张，所有色值复用。
- 上传前统一标准化：JPEG、1350×1800、尽量 ≤1.8MB；超过 2MB 自动压缩。
- 素材中心按素材名称定位；同名素材复用，不重复上传。
- 每个色值打开一次素材中心，选中正面图和背面图后确认。
- 已选卡片不重复点击，避免取消选中。
- 平台出现“图片品质不佳”时立即取消该次上传并记录原因；默认跳过当前商品或按重试规则处理。

### 7.6 敏感属性、体积与重量

- 优先照抄混合色第一行。
- 参数中填写了值则统一填入新增色值的每个尺码。
- 半自动模式下这一步交人工完成。

### 7.7 价格、库存与 SKU

- 申报价格默认逐尺码、逐站点沿用混合色的已核价价格。
- 混合色某站点为空时使用备用申报价（默认 300）。
- 库存默认 500。
- SKU 分类默认单品。
- SKU 货号必填。
- 提交前严格自检：价格、属性、库存、SKU、图片数量不完整则不提交。

### 7.8 提交与状态回写

- 全部色值完成后点击提交。
- 点击提交后进入“待确认”状态，回到列表核对“信息修改中/修改成功”。
- 成功、失败、超时、待确认都会写入状态列。
- 任务结束后导出带“运行汇总”工作表的 Excel。

### 7.9 失败、超时与重试

- 单商品失败自动重试 1 次。
- 连续无进展超过阈值：记录“卡死超时”，跳过当前商品，继续下一个。
- 失败项可点“重试失败（N）”，只补跑未成功项。
- 图片合规异常、提交结果未确认等不可盲目重试的情况会停止当前批次并标记待确认。

### 7.10 多色 SKC 模板

任务准备页提供“下载多色 SKC 模板”：

- 文件名：`多色SKC清单-模板.xlsx`
- 工作表：`多色SKC清单`
- 表头：`多色 SKC ID`、`状态`

模板只提供标准格式，不参与主流程执行。

## 8. 轮播图维护

### 8.1 入口与输入

任务列表页“轮播图维护”：

- 商品 ID 输入框支持多行、逗号、空格分隔。
- “导入 ID 文件”支持 xlsx / csv / txt，自动去重并保留顺序。
- 选择删除第几张（1–10）。
- 可选同时新增图片（可多选本地图片）。
- 默认勾选“安全演练（不提交）”。

### 8.2 单 ID 流程

1. 进入并锁定 `/material/image-task`。
2. 点击“发起图片/视频更新”。
3. 输入当前商品 ID（SPU/SKC/SKC货号）。
4. 点击“确认”。
5. 进入 `/goods/images-edit?productId=<ID>&from=selfTask`。
6. 对每个色值轮播图组删除指定顺序的图片。
7. 如勾选新增，逐个色值打开素材中心，上传/选择图片并确认。
8. 安全演练到此结束；正常模式继续点击“提交”。

### 8.3 多色值规则

- 每个色值组对应一个轮播图区域。
- 对所有色值组执行同一个“删除第 N 张”。
- 勾选新增时，每个色值组都新增所选图片。
- 新增图片统一裁剪 1350×1800。

### 8.4 批量顺序执行

- 多个 ID 按输入顺序执行。
- 一个 ID 的全部色值完成后，自动返回图片更新任务页并处理下一个。
- 每个 ID 记录：ID、状态、色值组数、每组最终轮播图数量。
- 全部结束显示“全部完成 N/N”。
- 中途可停止；失败时状态栏显示具体原因。

### 8.5 安全演练与正常提交

- 安全演练：完成删除/新增，不点提交；完成一个 ID 后继续下一个。
- 正常模式：点击提交，等待成功提示或页面跳转；确认成功后才进入下一个。
- 无法确认提交结果时停止批次并标记 `submit-pending`，避免重复提交。

### 8.6 异常处理

- 某色值图片不足第 N 张：停止并提示具体色值。
- 找不到素材中心/删除图标：停止并提示页面结构变化。
- 新增图片上传失败/合规拦截：停止并记录图片名。
- 批量中某个 ID 失败：停止批次，保留已完成 ID 的结果。

## 10. 多窗口与多店铺

- 每个比特浏览器配置有独立 IndexedDB 任务库。
- 不同窗口可并行处理不同货号任务。
- 同一窗口同一时间只允许一个任务运行；用任务租约防止重复执行。
- 图片文件夹需要在每台电脑/每个浏览器配置里重新选择一次。

## 12. 非功能需求

- **稳定性**：页面跳转、刷新、多标签页切换后可续跑；卡死可跳过。
- **安全性**：默认安全演练；严格自检；提交结果未确认时不重复提交。
- **性能**：图片只标准化本轮需要的数量；批量上传/裁剪；大图自动压缩。
- **兼容性**：Chrome MV3 / 比特浏览器；页面选择器使用类名前缀和文本兜底。
- **可维护性**：版本号、变更记录、PRD、技术设计、使用公告必须同步。

## 13. 验收标准

### 13.1 商品图片自动编辑

- SKC/SPU 清单可导入，状态列可回写。
- 新增 n 个色值、填货号、上传正/背面图、裁剪、选中、确认、提交全流程可执行。
- 多任务准备后可按队列顺序执行，成功/失败/超时统计正确。
- 失败可重试；卡死可跳过；图片合规异常有明确原因。

### 13.2 轮播图维护

- 多行/逗号/文件导入多个 ID，去重并保留顺序。
- 9542570366 的 4 个色值组均删除第 5 张并新增 1 张，最终 7/5/5/5。
- 45687392555 单色组删除第 5 张并新增 1 张，最终 5 张。
- 两个 ID 自动顺序执行，最终显示“全部完成 2/2（安全演练，未提交）”。

### 13.3 UI

- 缩小按钮隐藏整个插件框，悬浮按钮可恢复。
- 面板可拖动/拉伸，皮肤和位置持久化。
