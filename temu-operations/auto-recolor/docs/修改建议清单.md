已确认的 5 条决策：
1. 所有图片（正面图 + 背面图）统一裁成 **1350×1800**。

## 一、必须解决的核心坑

### P1　素材名带不确定序号（`DWRG03-26`、`X面料图-31`）
**问题**：上传后素材名 = 原文件名 + `-序号`，序号全局递增且不可预测，无法用「刚才那张」来定位。

**建议方案（上传登记表）**
1. 每次要上传一张图时，先在素材中心用「素材名称」搜索该文件的**文件名前缀**。
2. 命中唯一 → 直接选中使用，不再重复上传（顺带解决 P2 去重）。
3. 未命中 → 走本地上传 → 裁剪 → 保存。
4. 上传后立刻把「实际素材名 + 图片序号」登记到任务状态里，本次任务内后续轮次直接用登记名精确选中。

> **需要你定**：搜索命中**多个同名素材**（你历史上传过同一文件）时怎么办？
> 我的推荐：取序号最大的那一个（最新）并写警告日志，不打断流程。
> 备选：暂停并让你人工确认。

---

### P2　素材内容去重（“无需重复上传”弹窗）
**问题**：走查时上传 `Z尺码表.jpg` 直接弹「素材中心已有如下素材，无需重复上传」。

**建议**：由 P1 的「先搜后用」覆盖绝大多数情况；同时保留兜底：一旦该弹窗出现，自动点「关闭」→ 回到列表按名称前缀选中对应素材。

> 需要你定：无需额外决策，按上执行（除非你希望遇到该弹窗就暂停）。

---

### P3　正面图/背面图都统一裁 1350×1800（已确认）
**实现细节**：裁剪窗「图片尺寸」宽/高两个输入框，写入 `1350` / `1800` 后点「确认裁剪」，再点「保存」。

> 注意：走查实测背面图默认就是 1350×1800；主图默认是源图尺寸（1792×2389），**必须显式改写**。

---

### P4　站点文案错别字 / 表述差异
| 位置 | 页面实际 | 插件匹配策略 |
|---|---|---|
| 裁剪窗 | `待载剪(N)`（错别字） | 关键字集合：`待裁剪` / `待载剪` |
| 编辑入口 | `编辑其它商品信息`（不是“其他”） | 关键字包含匹配 |
| 列表页 | 需求写「全国」，实际是「全球」 | 只用 url 判断，不依赖标签文字 |

**建议**：所有文案匹配走「包含 + 多候选」，并集中放在一个 `texts.js` 里，页面文案一变只改一处。

---

### P5　弹窗可能同时存在多个（素材中心 / 裁剪 / 去重提示 / 上传列表浮层）
**建议**：统一「取最后一个可见且含关键文本的弹层」；对每一类弹窗写独立的 `waitOpen / waitClose` 判定；操作前先关掉其它遮挡层（按 Esc + 点遮罩）。

---

### P6　商品被平台锁定（原色值行不可改）
**建议**：插件启动时先检测原色值行的 `upload-trigger` 是否带 `disabled`：
- 带 disabled → 按计划只操作**新增行**（当前方案）。
- 不带 disabled → 仍然是只新增行（保持一致，避免误改线上图）。

> 需要你定：**永远只新增**，还是「未锁定时允许修改原行」？我的推荐：**永远只新增**。

---

### P7　提交行为未验证（最快的一次点击性风险）
**建议**：首轮做一次**试运行**：只跑 1 个 SKC、`n=1`、`X=2`、自动提交，人工旁观确认：
- 是否有二次确认弹窗？
- 提交后是 toast 还是跳转？
- 有没有“色值名不合法 / 货号重复 / 图片数量不足”之类的报错？

确认通过后再全量跑 Excel。

> **需要你定**：是否同意先试跑 1 个 SKC？（推荐同意，成本约 3–5 分钟）

---

### P8　提交成功后的校验
**建议**：提交后回到列表页再查一次该 SKC，校验：
- 色值行数 = `n + 1`
- 每个新增行轮播图 ≥ 3 张
- 货号 = A

不通过则记入报表并提示（不影响其它 SKC 继续）。

---

### P9　货号 `A` 是否需要序号
**风险**：同一 SPU 下 4 个新色值货号都写 `DWRG`，平台**有可能**校验重复。

**建议**：参数 A 设计成**模板字符串**，支持 `{i}` 占位（i 从 2 开始）：
- 填 `DWRG` → 所有新增行都是 `DWRG`
- 填 `DWRG{i}` → `DWRG2`、`DWRG3`、`DWRG4`、`DWRG5`

> **需要你定**：新色值货号是**全部相同**（`DWRG`），还是要**带序号**？

## 二、流程健壮性相关的坑

### P10　未提交的改动只存在页面内存里
**结论**：编辑页一旦刷新 / 关闭 / 平台自动重载，**新增的色值行和已上传到该行的图片全部丢失**（素材库里的图不会丢）。

**建议**：
- 断点粒度 = **整商品**：某个 SKC 失败/中断，恢复时重新进入编辑页重做。
- 但恢复时先看当前 DOM：若页面还活着且已存在 `Mixed Color2` 行，则**从该行继续**，不重复新增、不重复上传。
- 每个色值完成后立即写 `chrome.storage`，保证「能续则续」。

> **需要你定**：失败时是**自动重做该商品 1 次**（仍失败则暂停等待你），还是**立刻暂停等人工**？
> 我的推荐：自动重做 1 次 → 仍失败暂停。

---

### P11　编辑页加载横幅「正在获取商品数据，请勿关闭此页面」
**建议**：进入编辑页后先等横幅消失（或等待规格表可交互），再开始操作；每次操作前校验当前标签页 URL 含 `/goods/edit?`。

---

### P12　页面内部滚动容器（`window.scrollTo` 无效）
**建议**：一律 `scrollIntoView({block:'center', behavior:'instant'})` → 延时 300ms → 取 `getBoundingClientRect()` → 校验元素在视口内 → 再派发真实鼠标事件。

---

### P13　`element.click()` 对多个组件无效
**建议**：统一走「真实鼠标事件」（mousedown → mouseup → click，带 clientX/Y）。走查中「查询按钮、素材卡片、确认按钮」都靠这个才生效。

---

### P14　上传是慢操作 + 网络可能抖动
**建议**：
- 单张上传等待上限 60s，失败重试 2 次；重试仍失败 → 记录并暂停。
- 每步之间 300–800ms 随机间隔，串行执行，不做并发。
- 界面显示当前进度与「暂停 / 继续 / 停止」。

---

### P15　“上传列表显示上传成功”这个判定不可靠
**实测**：素材中心里上传列表面板在空闲时显示「暂无上传记录」。

**建议**：三层判定，任一成立即算成功：
1. 上传列表面板出现该素材且状态 = 上传成功；
2. 素材中心网格出现「上传前不存在的」新素材（列表 diff）；
3. 出现「无需重复上传」弹窗（说明库里已有，等同于成功）。

## 三、参数与边界校验

### P16　主图数量与顺序
- 必须**自然数字排序**：`DWRG03 < DWRG04 < … < DWRG010 < … < DWRG033`（Windows 默认字典序是错的）。
- 启动前校验：`SKC 数 × n ≤ 主图张数`，不足则**不执行任何页面动作**，直接报错停止本轮（按你的要求）。

---

### P17　色值数量上限
**建议**：`n ≤ 7`，且新增后色值总数 = `原色值数 + n`，若超过平台上限（建议按 10 校验）→ 报错跳过该 SKC。

> **需要你定**：平台色值上限你知道确数吗？不知道我就按 10 做软校验（超过只警告不阻断）。

---

### P18　Excel 与 SKC 校验
**建议**：
- 读取 B 列（识别表头 `skc ID`），跳过空行/非数字行；
- 重复 SKC 自动去重；
- 一个 SKC 查到多行结果时取第一行并记警告；
- 查不到结果 → 跳过并写报表。

---

### P19　扩展读取本地文件夹的授权
**建议**：用 File System Access API —— 面板上放「导入主图文件夹 / 导入背面图文件夹」两个按钮，点一次授权后把句柄存 IndexedDB 复用；浏览器不支持时退化为 `<input webkitdirectory>`。

> **需要你定**：能接受「首次点一次按钮授权文件夹，之后自动复用」吗？（推荐可以）

---

## 四、自动提交的额外保护（因为已确认“直接提交”）

### P20　提交前的本地校验
提交前逐项自检，任一项不过就**跳过该商品并报告**，不提交：
- 每个新增色值的轮播图 ≥ 3 张；
- 色值名非空且按 `Mixed Color2…n+1` 命名；
- 货号非空；
- 无残留弹窗（素材中心 / 裁剪 / 去重提示都已关闭）。

### P21　提交失败的可回退性
**建议**：提交失败时保留编辑页标签页不关闭，附截图 + 平台原文提示，写进报表，继续下一个 SKC。

### v0.10.5 轮播图 0 张误判

- 内部内容区原来有 78vh / 70vh 两处高度上限，面板拉高后内容不填满，底部出现空白。
- 去掉高度上限，内容区改为弹性纵向布局，活动页签自动占满并内部滚动，底部按钮始终贴底。
