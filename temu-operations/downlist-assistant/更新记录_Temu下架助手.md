# Temu 下架助手更新记录

## v2.6.0

日期：2026-10-31

- 新增“删除待发布商品并保存主图”模式。
- 先保存图片，再到商品列表“未发布到站点”按 SPU 查询。
- 逐个删除该 SPU 下的全部 SKC，并确认列表不再残留待发布记录。
- 新增“是否为多色值商品”勾选项。
- 勾选后保存第一个轮播图分组中的第一张原图；未勾选时仍保存普通主图。
- 结果 Excel 增加“图片来源”，区分普通主图与轮播图。

## v2.5.2

日期：2026-10-31

- 修复高级设置中的超时参数恢复时单位不一致的问题。
- 修复 SPU 查询超时显示为 `0`、实际被压缩为 15 毫秒的问题。
- 查询、图片、文件、下架和核验超时均恢复为秒转毫秒的正确范围。
- 为页面消息增加最小 1 秒的防御性超时，避免异常配置导致立即跳过。

## v2.5.1

日期：2026-10-31

- 修复直接填写识别到 SPU、但导入后任务数为 0 的问题。
- 统一文本框与 Excel 导入使用的任务行构建逻辑。
- 增加直接输入、重复项和异常长度 SPU 的自动化测试。

## v2.5.0

日期：2026-10-31

- “SPU 数据”区域新增直接填写文本框，无需先制作或复制 Excel。
- 支持换行、空格、逗号、中文逗号和分号分隔。
- 自动提取 8-20 位 SPU，忽略序号等短数字并自动去重。
- 支持点击按钮或按 `Ctrl+Enter` 导入任务列表。
- 直接填写与 Excel 导入共用查询、主图保存、下架、失败重试和结果导出流程。

## v2.4.1

日期：2026-10-23

- 新增 `下架SPU模板.xlsx`。
- 插件 Excel 区域增加“下载下架 SPU 模板”按钮。
- 模板随扩展包分发，不需要额外下载或安装。
- 模板预填 `1-100` 序号和 100 条空白数据行，SPU ID 列按文本保存。
- 导入时自动跳过未填写 SPU 的预留行，避免生成空任务或格式异常记录。

## v2.4.0

日期：2026-10-22

- 增加可自定义的超时参数。
- 支持分别设置 SPU 查询、图片下载、文件下载、下架提交和列表核验超时。
- 增加参数上下限校验和“恢复默认超时”。
- 自定义参数保存在当前浏览器实例中，多开环境互不影响。
- 面板增加醒目的超时策略说明。

## v2.3.0

日期：2026-10-22

- 增加查询、图片下载、浏览器下载、下架提交和商品核验的分阶段超时。
- 查询或图片阶段超时后自动标记“超时已跳过”，继续处理下一行。
- 下架提交阶段超时标记“超时已跳过（需复核）”，避免自动重复下架。
- 超时跳过后自动刷新工作页面，清理残留页面状态。
- “重试失败项”会包含可重试的超时项，但排除“需复核”项。

## v2.2.0

日期：2026-10-22

- 新增“重试失败项”按钮。
- 自动统计可重试的失败数量。
- 只重跑“未查到、超时、处理失败、下架失败”项目。
- 成功项、重复项和“需复核”项不会被重复执行。
- 重试继续遵守当前演练/下架模式和授权规则。
- 修复默认“待更新”栏导致的检索遗漏：查询前自动切换到“全部”栏。

## v2.1.0

日期：2026-10-21

- 查询 SPU 前自动切换到“全部”任务栏。
- 修复默认停留在“待更新”栏时部分 SPU 检索不到的问题。
- 使用 SPU `3617000192` 完成实机验证。
- 继续采用纯浏览器扩展和多开架构，不依赖 Windows 程序。

## v2.0.0

日期：2026-10-20

- 改为纯 Chrome MV3 扩展，不再依赖 Windows 本地助手。
- 移除 Native Messaging、固定 HTTP 端口和 Windows 安装程序依赖。
- 支持 File System Access API 写入用户选择的文件夹。
- 未选择文件夹时保存到浏览器下载目录。
- 每个浏览器实例独立运行，支持多开。
- 默认直接使用当前 Temu 页面，BitBrowser ID 仅保留在高级设置。

## v1.3.0

日期：2026-10-20

- 删除常驻的浏览器 ID 输入框。
- 默认直接使用当前已打开的 Temu 页面。
- BitBrowser ID 移入默认折叠的“高级设置”。
- 留空 BitBrowser ID 时不再调用比特浏览器 API。
- 指定比特窗口不可用时自动回退到当前 Temu 页面。

## v1.2.1

日期：2026-10-20

- 增加醒目的“安装本地助手.cmd”入口。
- 安装程序优先使用压缩包内现成的 `TemuDownlistHelper.exe`，不再强制要求同事电脑具备 C# 编译环境。
- 本地助手未连接时，面板日志会明确提示安装和重新启动步骤。

- 优化页面内面板标题栏与最小化按钮。

## v1.1.0
