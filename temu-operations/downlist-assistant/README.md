# Temu 下架助手合集

本目录合并了原 `下架保存` 项目中的多个相关子项目。

## 目录说明

- `temu-downlist-extension/`：当前自动下架与图片保存扩展，包含源码、模板和测试。
- `temu-adspend-monitor/`：Temu 商品推广花费监控扩展、需求与技术文档。
- `_spreadsheet_tools/`：用于检查和编辑下架清单工作簿的脚本。
- `_legacy_native_v1/`：旧版本地助手源码、安装脚本和安装入口。
- 根目录 Markdown 文件：需求、技术方案、更新记录和归档说明。

为保护本地数据，整理时没有提交测试截图、运行产物、原始工作簿备份和下载文件。
