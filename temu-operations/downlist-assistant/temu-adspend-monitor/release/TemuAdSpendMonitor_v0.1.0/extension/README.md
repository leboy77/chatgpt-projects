# Temu 商品推广花费监控扩展

版本：`0.1.0`  
当前状态：可加载原型；默认观察模式；真实暂停尚未执行 UAT。

## 功能

- 在商品推广页直接 `fetch` 今日推广明细，不刷新整个网页。
- 按自定义秒数定时读取。
- 展示每个 SPU 的今日花费、订单数和每单花费。
- 支持默认阈值和 SPU 专属阈值。
- 支持今日花费上限和每单花费上限。
- 观察模式只告警，不暂停。
- 自动暂停模式需要明确授权。
- 暂停前写入本地占位记录，避免重复提交。
- 暂停后重新读取，状态代码 `7` 才算核验成功。

## 安装

1. 在比特浏览器打开 `chrome://extensions/`。
2. 打开“开发者模式”。
3. 点击“加载未打包的扩展程序”。
4. 选择本目录：

   ```text
   temu-adspend-monitor/extension
   ```

5. 固定“Temu 商品推广花费监控”到工具栏。
6. 刷新“商品推广”页面。

## 首次使用

1. 打开 `https://ads.temu.com/ad-list.html`。
2. 点击扩展图标打开侧边栏。
3. 保持“观察模式”。
4. 设置刷新秒数，建议 `60` 秒，最低 `30` 秒。
5. 设置默认今日花费上限和/或默认每单花费上限。
6. 点击“保存设置”。
7. 点击“立即读取”，确认 19 条记录和金额正确。
8. 点击“开始监控”。

任意上限为 `0` 表示停用该规则。

## 自动暂停

必须先完成：

1. 用户指定一个允许测试的 SPU。
2. 确认该 SPU 的今日花费和每单花费口径。
3. 在观察模式核对至少 3 个周期。
4. 选择“自动暂停模式”。
5. 勾选授权确认。
6. 保存设置。

扩展只暂停状态代码为 `8`（推广中）的记录。暂停后重新读取并要求状态变为 `7`（手动暂停）。

扩展不会自动恢复推广。

## 状态与异常

- 页面不在商品推广页时不会运行。
- 离开页面后定时器停止。
- 登录失效、网络超时、接口结构异常会显示在侧边栏。
- 暂停结果不明确时不会在同一自然日重复提交。
