# 浏览器工具

本分类收纳可复用的浏览器诊断和自动化辅助工具。

当前项目：

- [chrome-cdp-probe](chrome-cdp-probe/)：用 Python 标准库连接 Chrome DevTools Protocol，检查页面标题、控制台事件和网络响应。
- [batch-traffic-accelerator](batch-traffic-accelerator/)：指定规格流量加速 `0.6.19`，支持 SPU/SKC 缓存、站点价格预检、持久化队列和真实任务提交。
- [temu-spec-traffic-accelerator](temu-spec-traffic-accelerator/)：Excel 优先的批量指定规格流量加速器 `0.2.2`，按 SKC × 站点展开任务并导出最终价格。
