# 指定规格流量加速插件 PRD

文档版本：`2.10`

对应产品版本：`v0.6.19`

状态：已实现

最后更新：2026-11-19

## 1. 产品目标

为 TEMU Seller Central 运营人员提供一个可配置、可排队、可暂停、可恢复的流量加速工具。

核心目标：

1. 按商品维度完成批量执行，而不是先跑完一个站点的全部商品。
2. 多个配置作为独立任务排队执行。
3. 自动检索商品列表并阻止旧缓存误执行。
4. 控制请求频率，避免平台“请求频繁”。
5. 明确区分配置异常和可重试失败。
6. Excel 导入结果可诊断、可追溯。

## 2. 用户

主要用户：TEMU 店铺运营人员。

使用环境：

- Chrome/Edge Manifest V3；
- BitBrowser 等 Chromium 浏览器；
- TEMU Seller Central 已登录。

## 3. 核心术语

| 术语 | 定义 |
| --- | --- |
| 商品 | 当前任务中的一组 SPU/SKC 配对 |
| 站点 | 德国站、法国站等经营站点 |
| 任务 | 一套独立参数、站点价格、商品缓存和执行策略 |
| 商品优先 | 一个商品处理完所有启用站点后，再处理下一个商品 |
| 配置异常 | 必须修改业务配置才能继续的问题 |
| 可重试失败 | 请求频繁、超时、网络或页面临时问题 |
| 指定规格价格模式 | 打开“调整申报价”，为每个 SKU 填写目标规格价或其他规格价 |
| 自动档位模式 | 读取平台“流量加权档位”，按目标价选择满足条件的档位后直接提交 |
| 让价优先模式 | 先尝试继续让价；不可用时按指定规格价和其他规格价匹配现有档位 |

## 4. 任务模型

每个任务必须独立保存以下数据：

- 任务名称；
- 创建任务时的店铺绑定快照；
- 商品获取方式：商品列表检索 / 表格导入商品 ID；
- 每组商品 ID 的类型：SPU / SKC；
- 货号关键词 X；
- 可选商品规格 Y；
- 商品 ID 类型：SPU 或 SKC；
- 站点及站点价格快照；
- 指定规格价格；
- 其他规格价格；
- 加速方式：指定规格价格 / 自动匹配加速档位 / 让价优先；
- 自动档位多档匹配策略：优先更多流量 / 优先更少让价；
- 每个站点的档位匹配目标价；
- 加速时效；
- 商品间隔；
- 空白价格阻断规则和提交开关；
- SPU/SKC 商品缓存快照；
- 缓存对应的 X、Y 和扫描时间；
- 任务状态、执行日志和结果。

任务加入队列后，修改当前配置不得影响已经加入队列的任务。

## 5. 功能需求

### TASK-001 创建任务

用户完成一套参数后，可以点击“加入任务队列”。

系统应：

1. 验证至少有一个启用站点。
2. 自动确认商品缓存与当前 X/Y 一致。
3. 缓存不一致时自动检索商品列表。
4. 保存任务配置和商品缓存快照。
5. 清空或保留当前配置进入下一次编辑，由界面明确提示。

### TASK-004 检索方式和区域

每个任务必须选择：

```text
商品获取方式：商品列表检索 / 表格导入商品 ID
检索方式：SKU 模糊查询 / 单类目检索
平台区域：欧洲区 / 美国区 / 全球区
```

“商品列表检索”和“表格导入商品 ID”是同级的商品池来源：

- 商品列表检索从当前 TEMU 商品列表扫描；
- 表格导入从标准表直接读取 SPU ID 和 SKC ID；
- 表格导入不要求打开或扫描商品列表；
- 导入行必须明确属于 SPU ID 或 SKC ID。

页面重载或浏览器重启后，必须从持久化的 `cacheMeta.source` 恢复商品来源标记。只要已有导入商品，顶部状态就必须显示“表格导入 N 组”，不得再次提示“尚未载入商品，请先检索商品列表”。

单类目任务必须选择一个类目。货号 X 和规格 Y 都是可选的二级过滤条件。

同一个任务只能包含一个类目；多个类目必须创建多个任务。

商品列表是否提供“商品规格名称”筛选框由 TEMU 页面版本决定。该筛选框不存在时，任务仍应按货号和/或类目扫描，不得因此反复打开新商品列表。规格 Y 继续在流量分析填价阶段用于区分目标 SKU。

### TASK-005 悬浮入口

商品列表和流量分析页右下角保留插件悬浮入口。

- 点击打开侧边栏；
- 支持拖动并保存位置；
- 拖动结束时不得误触打开插件。

### TASK-006 店铺绑定

插件从 TEMU 商家中心页头读取当前店铺名称，用户点击“绑定店铺”后保存绑定快照。

- 未绑定店铺不能创建或执行任务；
- 每个任务保存创建时的店铺名称、域名和区域；
- 页面店铺、当前绑定、任务快照三者不一致时阻止执行；
- 切换到其他店铺后必须重新绑定，并重新导入对应环境或重新配置价格；
- 店铺不匹配只阻止执行，不自动删除原有任务。

### TASK-002 队列持久化

任务队列必须保存到 `chrome.storage.local`，浏览器关闭后仍保留。

保存内容：

- 排队任务；
- 当前执行任务；
- 当前任务执行到哪个商品和站点；
- 暂停、失败和异常状态；
- 日志。

### TASK-003 队列管理

用户必须能够：

- 添加任务；
- 编辑尚未执行的任务；
- 删除尚未执行的任务；
- 删除已暂停的任务，并清理队列当前执行指针；
- 拖动调整排队顺序；
- 暂停整条队列；
- 继续整条队列；
- 重试可重试失败项。

正在执行的任务不能删除，只能先暂停或等待完成。

### SCAN-001 自动检索

参数变化导致缓存过期时，生成检查或开始执行必须自动检索。

检索顺序：

1. 优先当前活动商品列表标签页；
2. 查找其他正常 `goods/list` 页面；
3. 跳过存在“确认提交本页/放弃调整价格”等遮罩的页面；
4. 没有可用页面时自动新开商品列表；
5. 自动切换商品列表页的查询类型、货号、可选规格和分页；
6. 完成后回到检查或执行流程。

### SCAN-002 操作锁与进度

任意时刻只允许一个商品扫描流程。

扫描期间：

- “生成检查”“开始执行”“检索商品列表”统一锁定；
- 重复点击不得启动第二个扫描；
- 显示当前页、已发现 SPU/SKC 数量、扫描耗时；
- 扫描结束后释放全局锁。

### SCAN-004 商品数量校验

商品查询后必须等待：

1. `正在获取商品数据，请勿关闭此页面`等加载提示消失；
2. 当前页表格数据连续稳定；
3. 当前页实际商品行数达到平台结果总数要求的数量。

商品表使用虚拟滚动时，插件必须在当前页内部完成滚动收集，不能只读取首屏可见行。

扫描结束后按平台底部分页区域“共有 N 条”核对实际读取行数：

```text
实际读取行数 == 平台结果总数
```

不一致时：

- 返回数量校验失败；
- 不覆盖已有商品缓存；
- 不进入任务预检；
- 不开始执行；
- 提示平台总数和实际读取数。

### SCAN-003 缓存保护

缓存必须记录扫描时的 X、Y。

参数修改后：

- 旧缓存标记为“旧缓存”；
- 阻止执行；
- 自动触发重新检索后解除阻止。

### SCAN-005 检索日志与 ID 类型修复

商品定位检索日志必须区分两个同级来源：

```text
商品列表检索：
  开始日志：模式、货号、类目、规格
  完成日志：页数、平台总数、实际读取数、缓存数量

表格导入：
  导入日志：文件名、SPU 数量、SKC 数量、去重数量
```

执行时必须继续记录本次查询使用的是 SPU 还是 SKC、具体商品 ID、地区、站点数量，以及实际送入流量分析查询框的 ID。

当旧表格把 11 位 SPU 填入 `SKC ID` 列时，迁移必须把记录修正为 SPU，并把未提交的“缺少 SPU ID”执行项恢复为待处理。迁移完成后只追加一条汇总日志，队列保持暂停，不得自动提交。

### EXEC-006 页面连接自动恢复

扩展更新、页面重载或标签页导航后，旧 content script 可能失联并返回：

```text
Could not establish connection. Receiving end does not exist.
```

插件不得因为一次页面消息连接失败直接暂停整条队列。首次发送失败时必须自动向目标 TEMU 标签页重新注入 `content/content.js`，随后重试当前消息一次。

恢复成功时：

- 继续当前商品，不重复创建任务；
- 在执行日志写入“执行页面连接已恢复”；
- 当前站点尚未获得的返回结果按原流程处理。

自动注入仍失败时，队列暂停并报告“页面脚本连接断开，自动恢复失败”，不得在未确认页面状态时继续提交。

店铺名归一化必须忽略 TEMU 页头附加的关注数，例如：

```text
带动态关注数的店铺名 == 店铺主名称
```

同一店铺不得因为页头展示位置不同而误暂停队列。

### EXEC-007 商品 ID 类型枚举兼容

TEMU 流量分析的“商品ID查询”类型选择器在不同页面版本中可能默认显示：

```text
SPU / SKC / SKU
```

插件必须把三种值都识别为同一个类型选择控件。当任务目标类型为 SPU 或 SKC 时，先读取当前值，再切换到目标类型，并在切换后重新读取控件确认。

如果旧版本已因“没有找到商品 ID 类型选择框”生成未提交异常，升级时必须恢复为待处理，不得要求用户重建任务。

### EXEC-008 系统性异常熔断

同一商品至少 3 个站点、全部未提交，且所有站点返回完全相同的配置错误时，视为页面级或插件级系统异常。

触发条件不包括正常业务结果，例如：

- 没有获取加速资格；
- 未找到某站点商品行；
- 商品已在流量加速中。

触发系统性异常后：

- 当前商品未提交的站点恢复为待处理；
- 队列自动暂停；
- 日志记录相同错误和系统保护原因；
- 不继续处理后续商品。

### PERF-001 单执行实例

同一时刻只允许一个插件页面持有队列执行权。

- 执行权通过后台租约管理，默认有效期 60 秒，每 15 秒续租；
- 第二个插件页面不能启动另一个执行循环；
- 非执行页面可以请求全局暂停；
- 页面异常退出后，租约到期自动失效，不永久锁死。

### PERF-002 状态压缩和批量保存

持久化时不得保存全部待处理重复项。

- `pending` 且没有尝试记录的执行项由任务快照重新生成；
- 已完成、失败、异常、已提交或有尝试记录的项目必须完整保存；
- 热路径最多每 500ms 合并保存一次；
- 暂停、继续、队列创建等关键操作立即保存；
- 单任务保存日志最多 1000 条，队列日志最多 500 条。

### PERF-003 按页面渲染和窗口化

- 每次状态变化只刷新当前打开的页面；
- 隐藏页面在切换过去时再渲染；
- 执行时间线最多渲染最近 80 条有效进度；
- 商品列表和站点列表继续保持分页上限。

### PERF-004 自适应请求间隔

用户配置的商品间隔作为上限：

- 配置不低于 8 秒时，从 10 秒开始；
- 连续 3 个商品无可重试失败或请求频繁，间隔降低 1 秒；
- 最低降至 8 秒；
- 检测到请求频繁时恢复到用户配置值。

### PERF-005 价格弹窗确认

“确认”和“取消”按钮必须从当前“调整申报价”弹窗内部查找，不能使用页面全局按钮。确认后最多等待 15 秒，但弹窗一旦真正关闭立即继续。

参考申报价必须从整行文本读取，不能依赖固定列索引。缺少显式配置时，参考价上限校验默认开启。填写价格高于参考价时必须阻断提交，不能点击确认后等待超时。

弹窗关闭条件为：当前弹窗中不再存在至少 2 行可见规格。不能只判断页面中是否还能找到“调整申报价”文字。

### PERF-006 批量查询安全条件

TEMU 按 SKC 查询后的结果行只显示 SPU，不显示 SKC。因此 SKC-only 任务不得直接使用多 SKC 批量查询。

多 ID 查询只有在任务同时保存 SPU-SKC 映射，且软测验证返回行不会串商品后才可启用。

### RUN-009 当前未解决运行问题

当前 338 商品队列在现场执行中出现以下可重试失败，暂不自动重试：

- `继续让价确认加载超时`；
- `流量加速弹窗加载超时`；
- `平台提示成功，但未确认站点进入流量加速中`。

其中第三类包含已经点击最终确认但未完成状态回读的不确定提交，必须在下一版本单独调查。本次性能优化不能视为该问题已修复。

### EXEC-001 商品优先顺序

执行顺序必须是：

```text
任务
  → 商品 1
    → 地区 A 查询一次
      → 地区 A 内所有启用站点
    → 地区 B 查询一次
      → 地区 B 内所有启用站点
  → 商品 2
    → 重复以上流程
```

同一商品、同一地区只查询一次流量分析。

### EXEC-002 站点资格

对每个商品和站点：

1. 在查询结果中定位站点商品行；
2. 没有“立即开启”时记录配置异常；
3. 已在加速中时记录成功，不重复操作；
4. 有资格时进入加速和价格设置。

### EXEC-003 价格规则

目标规格 Y 有值时：

- 匹配 Y 的 SKU 使用指定规格价格；
- 其他 SKU 使用其他规格价格；
- 任一相关价格为空时阻断站点提交。

Y 为空时：

- 不区分目标规格；
- 所有 SKU 使用其他规格价格；
- 其他规格价格为空时阻断站点提交。

参考申报价只用于校验价格上限，不自动填入。填写价高于当前 SKU 参考申报价，或任一所需价格留空时，停止提交并记录配置异常。

### EXEC-006 自动匹配加速档位

“自动匹配加速档位”是独立加速方式，不打开“调整申报价”弹窗，也不把目标价写入日常申报价。

平台档位必须同时满足：

```text
目标价 <= 该档位每个 SKU 的对应申报价格
```

候选策略：

- 优先更多流量：选择满足条件的平均对应申报价格最低的档位；
- 优先更少让价：选择满足条件的平均对应申报价格最高的档位。

没有可读取档位或没有满足条件的档位时记录配置异常，不提交。
选择档位后点击“立即加速”和最终“确认”，并等待成功文本。

### EXEC-007 让价优先，档位兜底

独立第三种加速方式：

```text
检测“继续让价获取更多流量，去获取”
  ↓
存在：尝试打开“调整申报价”
      按目标规格价格和其他规格价格分别填写
      价格有效则确认并提交
  ↓
不存在、价格无效或无法继续：
      关闭调整申报价弹窗
      读取当前档位
      按每个 SKU 的目标规格价/其他规格价匹配
      默认选择满足条件且流量最高的档位
  ↓
没有满足目标的档位：
      允许按“档位兜底”规则选择最高流量档位
      日志明确记录使用了回退价格
```

如果界面没有“去获取”，直接进入档位兜底。请求频繁、页面超时等临时问题不触发价格回退，仍按可重试失败处理。

### EXEC-008 提交前价格回读

填写申报价后必须在同一弹窗内重新读取每个 SKU 输入框。只有实际值等于目标值才允许点击“确认”。

确认弹窗关闭后、点击“立即加速”前，再次打开申报价弹窗并核对平台已保存的值：

- 目标价格；
- 其他规格价格；
- SKU 对应关系；
- 币种标识。

任一不一致时立即停止，不点击“立即加速”，记录配置异常并保留差异明细。

### EXEC-009 提交后状态核对

最终确认后，除了等待成功文案，还必须确认目标站点行进入“流量加速中/查看效果”状态。平台提示成功但目标站点状态未确认时，记录为“已提交但结果不明”，不能标记为普通成功。

### EXEC-004 请求保护

默认配置：

- 商品间隔 15 秒；
- 0～3 秒随机抖动；
- 检测到请求频繁后立即暂停队列。

用户可调整间隔，界面最小值为 8 秒。

### EXEC-005 商品定位日志

日志必须明确体现：

```text
商品获取方式：商品列表检索 / 表格导入
商品列表检索：货号、类目、规格、页码、平台总数、实际读取数、缓存数量
表格导入：文件名、SPU 数量、SKC 数量、无效或未启用数量
执行定位：商品 ID 类型、具体 SPU/SKC ID、地区、站点数量
当前商品 / 当前地区 / 当前站点
```

### IMPORT-003 导入诊断

每次导入完成后必须显示：

- 识别站点数；

- 无法解析的价格行数；
- 无法解析行的国家代码和列名。

如果显示识别站点数大于 1，但最终只启用德国站，必须能判断原因：

- 数据中只有德国站填写了指定规格价格；
- 价格无法解析；
- 旧版本未替换站点表；
- 文件表头不匹配。

### IMPORT-004 v0.4.2 异常排查记录

该版本导入逻辑已经按“启用列或指定规格价格”自动启用，但仍无法确定异常 Excel 的具体原因，因为尚未取得异常文件。

- 必须通过导入诊断区分数据问题和解析问题；
- 诊断完成后补充根因记录。

### IMPORT-005 Excel 空单元格解析修复

v0.6.2 及以前版本把 Excel 中的自闭合空单元格误关联到后续非空单元格。示例：

```xml
<c r="F6"/><c r="G6"/><c r="H6" t="s"><v>18</v></c>
```

F、G 是空价格，H 的 `18` 是共享字符串索引。旧解析器把 `18` 当成指定规格价格，导致：

- 指定规格价格出现 `¥17` 或 `¥18` 占位值；
- 站点被错误自动启用；
- 空白其他规格价格也可能被错误填成占位值。

v0.6.3 必须：

1. 将 `<c .../>` 识别为空单元格；
2. 不把后续单元格的值归到前面的空单元格；
3. 清理已有状态中由解析器生成的 `17/18`；
4. 撤销由这些占位价格推导出的自动启用；
5. 保留用户在 CSV 或其他格式中明确填写的真实价格。

## 7. 异常、失败和重试

| 类型 | 定义 | 示例 | 自动重试 |
| --- | --- | --- | --- |
| 配置异常 | 修改业务配置后才能继续 | 无资格、价格超限、找不到站点行 | 否 |
| 可重试失败 | 临时请求或页面问题 | 请求频繁、超时、网络中断、页面未响应 | 否，用户手动重试 |
| 已提交但结果不明 | 已点击最终确认但没有明确结果 | 网络中断、结果页超时 | 否，先核对平台 |

请求频繁时：

1. 当前项记录可重试失败；
2. 整条队列暂停；
3. 不继续发送下一项请求；
4. 用户等待后可继续或重试失败。

## 9. 验收标准

1. ZSK 自动检索结果与正常商品列表一致。
2. 扫描期间重复点击不启动第二次扫描。
3. 扫描过程显示分页和数量进度。
4. 一个 SKC 的所有启用站点完成后才进入下一个 SKC。
5. 同地区同商品只查询一次。
6. 两个任务可独立保存不同 X、Y、价格和缓存。
7. 队列顺序可拖动，关闭浏览器后仍保留。
8. 请求频繁自动暂停，失败项可重试。
9. Excel 导入摘要能解释自动启用数量。
10. 安装包文件名包含版本号。
11. 已暂停任务可直接删除，删除后队列不会停留在旧执行指针。
12. 自动档位模式能读取真实档位并保持指定规格价格模式不变。
13. 批量相同 `¥17` 占位价会被清理，不会再次自动启用站点。
14. 自定义填价模式中任一必需价格留空时，站点停止提交并记录配置异常。
15. 自动档位模式默认选择满足门槛的最高流量档位，且不填写调整申报价。
16. 新安装不包含其他店铺的商品 ID、站点价格或任务。
17. 未绑定店铺时不能创建或执行任务。
18. 环境包只能在同店铺导入，且导入后运行中任务保持暂停。
