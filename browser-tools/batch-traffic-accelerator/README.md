# 指定规格流量加速

当前版本：`v0.6.17`。这是可连接 TEMU Seller Central 真实页面并提交流量加速的 Chrome Manifest V3 插件。

## 已实现

1. 在商品列表按货号关键词 X、商品规格 Y 查询，翻页缓存全部 SPU/SKC。
2. 商品规格 Y 可以留空；留空时不筛选规格，所有 SKU 使用其他规格价格。
3. 从表格导入站点、指定规格价格和其他规格价格。
4. 插件内置“下载标准表”，直接取得 59 个站点的标准 XLSX。
5. 点击站点行可单独启用站点并修改两个价格。
6. 目标规格或其他规格价格留空时阻断提交；参考申报价只校验上限。
7. 逐商品查询流量分析，按目标站点识别“立即开启”资格。
8. 自动选择加速时效、打开“去获取”、填写全部规格价格、确认申报价、点击“立即加速”和最终确认。
9. 商品间隔默认 15 秒并增加随机抖动；检测到请求频繁后自动暂停。

14. 同一商品、同一地区只查询一次流量分析。
15. 扫描期间有全局操作锁和分页进度。

## 标准表

点击侧边栏“下载标准表”，得到 `指定规格流量加速_标准导入模板.xlsx`。文件包含：

- `商品ID导入`：最多 1000 行商品 ID，SPU ID 和 SKC ID 分列，启用列带“是/否”下拉选项。
- `国家价格`：59 个站点，启用列带“是/否”下拉选项。
- 三个价格列为人民币数值格式，默认留空；自动档位模式只读取平台档位。

| 表格列 | 插件含义 |
| --- | --- |
| `国家代码` | 站点唯一标识 |
| `国家名称` | 显示为“德国站、法国站”等 |
| `分组` | 推导全球、美国或欧洲区 |
| `启用(是/否)` | 填写“是”才进入批量任务 |
| `指定规格价格(RMB)` | 目标规格 Y 的价格 |
| `其他规格价格(RMB)` | 非目标规格的价格 |
| `档位匹配价格(RMB)` | 自动档位模式的目标价上限 |
| `商品ID导入 / SPU ID` | 直接作为商品池使用的 SPU |
| `商品ID导入 / SKC ID` | 直接作为商品池使用的 SKC |

参考表包含 59 个站点，默认全部未启用。导入后会替换当前站点表，但不会修改填好的 XLSX。

## 默认参数

```text
货号关键词 X         默认留空，由每个任务填写
目标商品规格 Y       可选；留空时所有规格使用其他规格价格
商品 ID 类型         SPU ID
默认启用站点         无；导入标准表或环境后启用
指定规格价格         必须由用户填写
其他规格价格         必须由用户填写
加速时效             持续30天
商品间隔             默认15秒，自动附加0～3秒随机抖动
加速方式             指定规格价格模式
多档位策略           优先更多流量
```

`DWRG + Mixed Color2` 的当前商品总量为 45 条，规格筛选后实测得到 7 组唯一 SPU/SKC。插件会把每次扫描结果作为当前任务快照保存。

## 实际运行

1. 打开 TEMU 商品管理中的商品列表。
2. 选择商品获取方式：
   - 商品列表检索；
   - 表格导入商品 ID。
3. 商品列表检索时选择检索方式：
   - SKU 模糊查询：填写货号 X；
   - 单类目检索：填写类目完整路径，可选填写货号 X 和规格 Y。
4. 表格导入时直接导入标准表的 `商品ID导入`，不再扫描商品列表。
5. 选择欧洲区、美国区或全球区。
6. 商品列表检索时，修改参数后插件自动检索并缓存全部 SPU/SKC。
7. 下载并填写标准表；填写“指定规格价格”或“档位匹配价格”的站点会自动启用。
8. 点击“生成任务预检”，检查商品池、站点和价格。
9. 确认价格和提交模式后，点击“加入任务队列”。
10. 修改下一套参数并继续加入任务；每个任务保存独立快照。
11. 在“队列”页拖动排序、编辑或删除排队任务；暂停任务也可以直接删除。
12. 点击“开始任务队列”；插件按商品优先执行。
13. 中途可暂停；平台拒绝或结果不明会进入失败，可单独重试。

## 商品定位为什么不会漏

商品定位分两步：

```text
读取商品列表
  货号 X + 可选规格 Y
  翻页读取
  提取全部 SPU/SKC
  按 SPU + SKC 去重
  ↓
批量执行
  按任务依次执行
  每个商品在当前地区查询一次
  处理该地区全部启用站点
  再进入下一地区或下一商品
```

商品列表扫描负责建立候选集；实际执行时不会直接相信缓存页面，而是再次用 SPU/SKC 查询流量分析。日志会显示“商品定位检索：已载入 N 组候选”和每项的“商品定位检索并查询流量资格”。

如果修改了货号或规格但没有重新检索，检查页会把缓存标记为“旧缓存”，并阻止开始执行。商品列表页面存在“确认提交本页/放弃调整价格”等未完成调价窗口时，插件也会提示先打开一个正常商品列表标签页。

生成检查或开始真实执行时，如果检测到旧缓存，插件会自动：

1. 查找已打开的 `goods/list` 标签页，优先当前页。
2. 跳过存在批量调价遮罩的页面。
3. 自动切换到可用的正常商品列表页。
4. 没有可用页面时自动新开商品列表。
5. 检索完成后回到检查或执行流程。

## 单项执行流程

```text
切换目标地区流量分析
  ↓
输入 SPU 或 SKC 并查询
  ↓
在结果中定位目标站点
  ↓
没有“立即开启” → 异常：没有获取加速资格
  ↓
点击“立即开启”并选择加速时效
  ↓
点击“去获取”
  ↓
逐 SKU 填价并校验参考申报价
  ↓
确认申报价
  ↓
点击“立即加速”
  ↓
最终确认
  ↓
等待“流量加速成功”并记录结果
```

## 价格规则

```text
目标规格 Y：
  有配置价 -> 使用配置价
  没有配置价 -> 配置异常，停止提交

其他规格：
  有配置价 -> 使用配置价
  没有配置价 -> 配置异常，停止提交

填写价 > 当前 SKU 的参考申报价 -> 价格异常，停止提交
参考申报价只用于上限校验，不会自动填入
```

示例中 `Mixed Color2` 参考价为 `¥145.31`，`Mixed Color8` 为 `¥111.00`。`120 / 130` 会被价格校验阻断；`120 / 留空` 也会因缺少其他规格价格而阻断，不再自动使用参考价。

## 按价格自动匹配加速档位

在“加速方式”中选择 `按价格自动匹配加速档位`，然后点击每个站点填写档位匹配目标价。

```text
打开流量加速器并选择加速时效
  ↓
读取平台当前流量加权档位
  ↓
只保留“每个 SKU 对应申报价 >= 目标价”的档位
  ↓
优先更多流量：选择平均对应申报价最低的档位
优先更少让价：选择平均对应申报价最高的档位
  ↓
点击档位
  ↓
立即加速
  ↓
最终确认
```

自动档位模式不点击“去获取”，不打开“调整申报价”，也不会把目标价写入日常申报价。没有档位满足目标价时记录为配置异常，不提交。

## 让价优先，档位兜底

第三种加速方式会先检查“继续让价获取更多流量，去获取”。

```text
可以继续让价：
  打开调整申报价
  指定规格和其他规格分别使用各自价格
  校验通过后继续提交
  ↓
不能继续、没有入口或填价无效：
  关闭调整申报价
  按每个 SKU 的指定规格价格/其他规格价格匹配现有档位
  ↓
默认选择满足门槛的最高流量档
```

如果现有档位全部低于目标价格，按已确认的规则允许回退到最高流量档位。提交结果和日志会明确记录使用了“档位兜底”以及实际选择的档位价格。

## 状态定义

| 状态 | 含义 | 处理方式 |
| --- | --- | --- |
| 成功 | 已在加速中，或平台明确返回加速成功 | 不再重试 |
| 配置异常 | 没有资格、价格超限、缺少站点商品等需要修改条件的问题 | 修改配置后重新执行 |
| 可重试失败 | 请求频繁、超时、网络中断、页面未响应、已提交但结果不明 | 冷却后可点击“重试失败” |

配置异常不会自动重试，避免没有资格或价格超限时无限循环。可重试失败支持单独重试；检测到请求频繁时任务会自动暂停。

## 价格回读

点击确认前，插件会重新读取申报价弹窗内每个 SKU 输入框。确认关闭弹窗后，还会重新打开“去获取”，核对平台实际保存的价格。

```text
输入值与目标值不一致
  → 配置异常
  → 不点击“立即加速”

平台提示成功
  → 再检查目标站点行
  → 未进入流量加速中：已提交但结果不明
```

因此日志中的普通成功现在同时代表：价格已回读、站点已确认进入加速状态。

## 真实提交提醒

- “仅检查，不提交”默认关闭；点击“开始任务队列”会实际提交符合资格的商品。
- 平台提示流量加速器至少需要 `7×24h` 后才能手动停止，执行前应确认站点和价格。
- 如果执行中关闭页面、登录失效或通信中断，状态可能无法确认，应先到平台核对再重试。
- 遇到验证码、频控、账号异常或页面结构变化时，插件会停止继续推进并记录失败。

- 因为完整任务还包含弹窗和提交请求，查询未触发并不代表提交链路可同样快，所以正式执行采用更保守的 15 秒商品间隔。

## 在其他店铺或其他电脑使用

首次使用必须：

1. 在目标电脑加载已解压插件；
2. 登录对应 TEMU 商家账号；
3. 打开商品列表或流量分析；
4. 点击页头“绑定店铺”；
5. 重新导入该店铺的价格表并创建任务。

新安装默认不包含商品 ID、站点价格、任务或店铺绑定，避免把开发测试数据带入其他店铺。

同一店铺跨电脑迁移时，可在原电脑点击“导出环境配置”，在目标电脑点击“导入环境配置”。导入会替换当前参数、站点价格、商品缓存和任务队列，并要求店铺名称一致。

环境 JSON 不包含 TEMU 登录 Cookie、代理、浏览器指纹或账号密码。切换店铺后，旧任务会因店铺不匹配被阻止执行。

## 直接更新

扩展加载目录：

```text
<仓库根目录>\browser-tools\batch-traffic-accelerator
```

更新并原地重载：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\update-live-extension.ps1
```

运行后重新打开侧边栏即可，不需要下载安装包。
