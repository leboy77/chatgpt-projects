# 批量流量加速 Demo

这是一个 Chrome Manifest V3 插件 Demo，用于评审“TEMU 流量分析批量增长”的交互和流程。

完整打开步骤见 [统一使用入口](../../USAGE.md#四批量流量加速-demo)。

## 当前已实现

- 侧边栏操作界面；
- 内置 18 个模拟商品；
- 流量、转化、价格、毛利、库存和加速状态筛选；
- 让价后的预计价格与毛利预演；
- 分批模拟执行、停止、成功/失败记录；
- 运行状态持久化；
- CSV 导出；
- TEMU 页面通用表格扫描适配器；
- 在流量分析页面显示“批量加速”快捷入口。

## 当前没有做

- 不会修改 TEMU 真实商品价格；
- 不会调用 TEMU 或探果内部提交接口；
- 还没有接入当前 TEMU 页面真实的字段、价格档位和接口签名；
- 页面表格解析目前是通用启发式版本，具体选择器需要按实际页面校准。

## 加载插件

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录：

   ```text
   browser-tools/batch-traffic-accelerator
   ```

5. 点击浏览器工具栏中的“批量流量加速 Demo”图标，即可打开侧边栏。

## 独立预览

直接打开 `demo/preview.html` 可以查看插件在“经营分析 > 流量分析”页面内的视觉位置。

## 建议优先评审

- 当前筛选字段是否符合你的实际选品逻辑；
- 目标让价应该按百分比、固定金额，还是 TEMU 档位流量价；
- “预计毛利”的计算口径；
- 是否需要多店铺、多站点同时执行；
- 预演是否需要展示每个 SKU 的可申报价和风险原因；
- 执行成功应以页面提示、进度接口还是后续流量变化为准。
