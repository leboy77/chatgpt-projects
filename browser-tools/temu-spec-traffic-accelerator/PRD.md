# 批量指定规格流量加速器 PRD

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 版本 | v0.2 |
| 状态 | MVP 已实现，并完成 测试窗口 实测 |
| 日期 | 2026-11-19 |
| 目标环境 | BitBrowser Chromium 148，窗口标签 `脱敏测试窗口` |
| 目标页面 | `https://agentseller-eu.temu.com/main/flux-analysis` |
| 输入样例 | `test流量加速.xlsx` |

## 2. 一句话需求

读取 Excel 中的 SKC、站点、指定规格价格 Y 和通用规格价格 X，在 Temu 商品流量页批量检查商品是否可开启流量加速；对可开启商品进入超级流量加权申报价页面，将所有指定颜色组 SKU 的价格填为 Y，其余 SKU 的价格填为 X，并在提交前展示完整校验结果。

## 3. 目标

- 支持欧区、美国、全球三个区域，默认欧区。
- 支持从 Excel 批量导入任务，不要求逐条手工搜索。
- 在本地缓存 SKC、SPU、站点关系，减少重复查询和平台限流风险。
- 自动区分“可开启”“加速中”“无资格”“无商品/站点”“价格不合法”等状态。
- 按 SKU 名称动态识别指定颜色组，不写死尺码或颜色组数量。
- 在真正提交前展示区域、站点、Y/X、平台价格上限和填写行数。
- 每个任务保留可追溯的结果、原因、时间和处理记录。

## 4. 非目标

- 不处理账号登录、验证码、密码或浏览器指纹。
- 不绕过平台权限、风控、限流或安全检查。
- 不修改商品标题、类目、库存、日常申报价等与流量加速无关的数据。
- 不默认创建远端服务器或上传 Excel、SKC、价格、Cookie 等数据。
- 第一阶段不自动处理平台未定义的页面或接口错误。

## 5. 用户和场景

主要用户是负责 Temu 店铺运营的人员。用户已经明确每个站点希望使用的 Y/X 价格，希望通过一次导入完成多个 SKC 的筛选、开启和价格填写，同时保留失败商品和失败原因，便于业务复盘。

## 6. 输入数据

### 6.1 推荐格式

推荐使用单表逐行任务格式，每行对应一个 `SKC + 站点` 任务：

| SKC ID | 站点 | 指定颜色组 | 指定规格价格 Y | 通用规格价格 X | 备注 |
| --- | --- | --- | --- | --- | --- |
| 111111111111 | 德国站 | Mixed Color2 | 114.25 | 118.38 | 可选 |
| 111111111111 | 法国站 | Mixed Color2 | 120 | 125 | 可选 |

字段规则：

- `SKC ID` 必须按文本读取，不能转成数值后丢失前导零。
- `站点` 可填写“德国”或“德国站”；插件会清理空格和“（无偏远）”等备注，并自动补成平台使用的“德国站”“法国站”等名称。
- `指定颜色组` 默认 `Mixed Color2`，允许任务级覆盖。
- X、Y 必须是大于 0 的数值，支持最多两位小数。
- 同一轮任务中，`SKC ID + 站点` 必须唯一。
- 同一 `SKC ID + 站点` 出现不同 X/Y 时，整条冲突任务不得执行。

### 6.2 当前样例文件

当前 `test流量加速.xlsx` 的内容如下：

- `Sheet1`：站点、指定规格价格、通用规格价格。
  - 德国站：Y=115，X=125。
  - 法国站：Y=120，X=125。
- `Sheet2`：序号、SKC ID。
  - `222222222222`
  - `333333333333`
  - `111111111111`

当前文件没有在同一行绑定 SKC 和站点。已确认按每个 SKC 跑完价格表中的全部站点，再处理下一个 SKC。当前文件会按以下顺序生成 6 条任务：

1. `222222222222 + 德国站`
2. `222222222222 + 法国站`
3. `333333333333 + 德国站`
4. `333333333333 + 法国站`
5. `111111111111 + 德国站`
6. `111111111111 + 法国站`

兼容策略：

1. 首选让用户改成 6.1 的单表逐行格式。
2. 旧版双表自动按 SKC × 全部价格站点展开成任务。
3. 任务按 SKC 分组，SKC 顺序保持 Excel 首次出现顺序，站点顺序保持价格表顺序。
4. 组合结果只在面板中展示，不设置人工确认步骤。

## 7. 区域参数

| 界面名称 | 内部枚举 | 默认 |
| --- | --- | --- |
| 欧区 | `EU` | 是 |
| 美国 | `US` | 否 |
| 全球 | `GLOBAL` | 否 |

可见文案优先使用平台原文“欧区”，文档和代码可使用 `EU`，避免把“欧洲”误做成一个额外的区域。

### 7.1 指定规格参数

- 面板提供“指定规格 / 颜色组”输入框，默认 `Mixed Color2`。
- 使用者可按页面实际文案填写，例如 `Mixed Color2`、`混合色`。
- 导入 Excel 和继续执行时均使用当前参数；参数保存到本地状态。
- 同一 SKU 组的所有尺码使用 Y，其他颜色组使用 X；如果页面只有目标颜色组，则允许 X 组数量为 0。

## 8. 主流程

### 8.1 导入和预检

1. 用户选择 XLSX 文件。
2. 插件读取工作表，识别推荐格式或旧版双表格式。
3. 校验 SKC、站点、X、Y、重复项和冲突项。
4. 展示任务预览和预计操作数量。
5. 自动生成按 SKC 分组、组内按站点排序的任务队列。
6. 用户点击一次“开始执行”后，后续流程自动运行。

### 8.2 建立本地任务和查询缓存

1. 导入后的 SKC、站点、X/Y、执行顺序和结果状态保存到扩展本地存储。
2. 当前 SKC 查询一次，站点结果和 SPU ID 在该 SKC 的站点循环内复用。
3. 当前 SKC 全部站点结束后再次查询该 SKC，验证自动提交结果。
4. 页面刷新或扩展重开后恢复任务列表，已中断任务回到待执行状态。
5. 不要求一次性拉取全部商品目录；按 SKC 串行查询可避免批量输入上限干扰。
6. 查询后等待结果总数和行数据实际刷新；最多等待 60 秒。
7. 查询或分页失败自动重试；单个 SKC 仍失败时只结束该 SKC，继续处理后续 SKC。
8. 再次点击“继续执行”时只处理待执行和可重试任务，保留已加速、已跳过和其他终态结果。

### 8.3 查询加速资格

1. 打开或复用已登录的商品流量页面。
2. 切换到用户选择的区域，默认欧区。
3. 查询方式保持 `SKC`。
4. 按配置的批量大小输入 SKC，多个值用逗号或空格分隔。
5. 平台结果按 `SKC + 站点` 建立任务状态。

### 8.4 判定状态

| 页面表现 | 任务状态 | 后续动作 |
| --- | --- | --- |
| 出现“该商品已获得开启流量加速器机会” | 可开启 | 进入开启流程 |
| 出现“流量加速中”或已加速标识 | 已加速 | 不重复开启 |
| 找到 SKC 对应商品和站点，但没有开启资格文案 | 未获取资格 | 结束，记录页面原因 |
| SKC 不存在 | 无商品 | 结束，提示检查 SKC 或账号 |
| SKC 存在但没有目标站点 | 无目标站点 | 结束，提示该 SKC 未进入该站点 |
| 页面提示限流、登录失效或网络超时 | 待重试/阻塞 | 停止写入，等待恢复 |
| 价格高于平台参考申报价 | 已跳过-价格超限 | 不提交，记录逐行上限后继续下一条 |

“没有加速资格”和“商品未进入该站点”必须是两个不同原因，不能合并。

### 8.5 开启加速

1. 只对“可开启”任务点击“立即开启”。
2. 核对弹窗中的 SKC、SPU、站点与当前任务一致。
3. 读取加速时长和自动续期状态。
4. 通过“继续让价获取更多流量，去获取”进入超级流量加权价格页。
5. 读取平台参考申报价和页面提示，不直接采用平台推荐值。

当前平台默认选择“持续30天”，自动续期处于开启状态。页面同时提示开启后至少 7×24 小时才能手动停止。插件读取并保持当前平台默认值，不弹出人工确认，运行面板持续显示这两项和锁定说明。

### 8.6 填写 X/Y

1. 读取每个 SKU 的完整名称、日常申报价、输入框和参考申报价。
2. 将名称去除首尾空格并统一大小写后，以 `-指定颜色组` 后缀识别目标 SKU。
3. 目标颜色组的全部尺码填写 Y。
4. 其他所有 SKU 填写 X。
5. 不按行号、尺码或固定 36 条记录写值。
6. 每一行独立校验 `0 < 填写值 <= 本行参考申报价`。
7. 任意一行超出上限时，整条任务进入“已跳过-价格超限”，记录具体 SKU、期望价格和平台上限。
8. 超限任务不点击“确认”或“立即加速”，直接继续下一条任务。
9. 不自动截断价格，不把 X/Y 改成平台上限，也不对同一任务部分提交。

示例：

- `S-Mixed Color2`、`M-Mixed Color2`、`L-Mixed Color2`、`XL-Mixed Color2`、`XXL-Mixed Color2`、`XXXL-Mixed Color2` 全部填写 Y。
- `Mixed Color3`、`Mixed Color4`、`Mixed Color5`、`Mixed Color7`、`Mixed Color8` 下的全部尺码填写 X。
- 当前实测商品每个颜色组 6 个尺码，共 36 个价格输入行；数量应由页面动态读取，不能硬编码。

### 8.7 自动预检和提交

预检和执行面板至少显示：

- 区域、SKC、SPU、站点。
- 指定颜色组、Y、X。
- 目标 SKU 数、其他 SKU 数、总输入框数。
- 平台最低参考申报价、超上限行数。
- 加速时长、自动续期状态。
- 本次是预演、批量执行还是单条执行。
- 当前批次成功、失败、跳过和待处理数量。
- 价格超限跳过任务的数量、超限 SKU 和目标价格。

插件完成价格回读和行级校验后，自动点击“确认”和“立即加速”，不弹出人工确认。提交结果必须回到页面重新查询并确认状态，不能仅凭点击成功判断已完成。

## 9. 批量策略

- 默认一次处理一个“开启或提交”动作，避免并发写冲突。
- 查询可以批量，执行必须串行。
- 外层循环按 SKC 推进，内层循环处理该 SKC 的全部站点。
- 当前 SKC 的所有站点进入成功、已加速、无资格、无站点、价格超限跳过或其他终态后，才进入下一个 SKC。
- 不允许不同 SKC 的站点任务交叉执行。
- 页面列表可能分页，当前观测每页 30 条，需按任务查找目标行而不是只读第一页。
- 某条任务提交后结果不明确时，标记“提交结果未知”，禁止自动重试。
- 重新查询确认已经加速后再跳过，避免重复报名。
- 价格超限时跳过整条 `SKC + 站点` 任务，继续处理后续任务。
- 查询超时最多尝试 3 次；仍失败时记录该 SKC 的站点任务并继续下一个 SKC。
- 批次中断后保留持久化结果，从尚未完成或可重试的任务恢复。
- 新开页面、页面刷新或插件重开后，从持久化状态继续。
- 提供暂停、继续、跳过、停止批次和导出结果。

## 10. 结果和错误文案

| 错误码 | 用户文案 |
| --- | --- |
| `NO_PRODUCT` | 未找到该 SKC，请检查 SKC 或当前账号 |
| `NO_SITE` | 该 SKC 未找到目标站点 |
| `NOT_ELIGIBLE` | 没有获取加速资格 |
| `ALREADY_ACTIVE` | 该商品已加速 |
| `SKIPPED_PRICE_LIMIT` | 已跳过：填写价格高于平台参考申报价 |
| `SKU_MAPPING_MISMATCH` | 未完整识别目标规格，已停止提交 |
| `UI_VERSION_CHANGED` | 页面流程已变化，已停止避免误操作 |
| `RATE_LIMITED` | 平台查询受限，等待后继续 |
| `AUTH_REQUIRED` | 登录状态失效，请重新登录 |
| `SUBMIT_UNCERTAIN` | 提交结果未知，需重新查询确认 |
| `PARTIAL_SUCCESS` | 部分任务成功，详见结果明细 |

## 11. 本次实测结论

### 11.1 已确认可用

- 欧区页面可正常打开，商品 ID 类型可选择 `SKC`。
- 多个 SKC 可用逗号输入，实测 3 个 SKC 查询返回 36 条站点结果。
- 单次查询中 SKC `111111111111` 在德国站显示可开启。
- 可进入“调整申报价”页面，页面上展示每个颜色组和尺码的独立输入框。
- 目标颜色组 `Mixed Color2` 的 6 个尺码可独立识别。

### 11.2 阻断问题

德国站 SKC `111111111111` 的实测价格上限如下：

- `Mixed Color2` 每个尺码参考申报价为 114.25。
- 其他颜色组中最低参考申报价为 118.38。
- 工作簿给出的 Y=115 高于 114.25。
- 工作簿给出的 X=125 高于 118.38。

实际输入 115 后，平台立即显示“不得高于超级流量加权的参考申报价”；输入 114.25 后提示消失。

因此当前 X/Y 不能按原值提交到该 SKC 的德国站任务。插件必须执行逐行上限校验，并将该任务标记为“已跳过-价格超限”，不能直接批量填入或自动截断。

### 11.3 其他实测发现

- 单条查询 `111111111111` 时，欧区结果中的 19 个站点不包含法国站，说明“无加速资格”和“无目标站点”需要分别展示。
- 页面顶部提示：参加直降促销活动的商品，日常申报价发生下调后，需在 24 小时内检查营销活动调价待办，否则活动权益可能暂停。
- 本次验证完成到价格输入和校验，已关闭弹窗，未点击最终“确认”或“立即加速”，未产生加速报名。

## 12. 验收标准

### 12.1 导入

- 能识别当前双表文件，并在未确认绑定前禁止执行。
- 能识别推荐单表格式并生成逐行任务。
- 重复项、冲突价格、空值和非法数字有明确提示。

### 12.2 查询

- 欧区、美国、全球可切换，默认欧区。
- 批量查询后能准确对应 SKC、SPU 和站点。
- 分页结果不会遗漏。
- 限流时停止并支持断点继续。

### 12.3 价格

- 所有目标颜色组 SKU 填 Y。
- 所有非目标颜色组 SKU 填 X。
- 不遗漏、不串行、不覆盖错误输入框。
- 超参考价时整条任务标记为“已跳过-价格超限”，并继续处理后续任务。
- 未找到“立即加速”按钮时，将当前站点标记为“已跳过·无立即加速按钮”，继续处理后续站点。
- 超限结果包含期望价格、平台上限和具体超限 SKU。
- 输入值回读一致后才允许自动点击最终确认。
- 提交前逐 SKU 回读最终加速提价，并保存到任务结果。

### 12.4 提交和结果

- 执行前自动生成并显示预检摘要。
- 用户点击一次“开始执行”后，不再要求逐条或逐 SKC 人工确认。
- 当前 SKC 的所有站点完成后才进入下一个 SKC。
- 提交后必须重新查询验证状态。
- 重复运行不会重复报名已加速商品。
- 结果可筛选并导出，至少包含 SKC 顺序、站点顺序、任务键、最终状态、原因、平台上限、期望填写值、超限 SKU 列表和时间。
- 执行结果主表增加“最终加速提价明细”；同一文件的“最终价格明细”工作表按 SKU 逐行导出最终提价、价格类型和参考申报价。

## 13. 已确认规则

1. 每个 SKC 跑完价格表中的全部站点后，再处理下一个 SKC。
2. 当前双表文件按 3 个 SKC × 2 个站点自动展开为 6 条任务。
3. 价格超过平台参考上限时，跳过该站点任务并在结果中标记，继续处理该 SKC 的后续站点；不自动截断价格。
4. 用户点击一次“开始执行”后，不需要人工确认。插件自动完成价格确认、立即加速和提交后回查。
5. 加速时长和自动续期保持平台当前默认值，不自动修改页面默认设置。
6. 当前仅德国站完成价格规则实测。法国站需要 SKC 实际进入站点后才能验证。
7. 表内站点名称允许省略“站”，插件会自动规范化。
8. 查询超时后自动重试；单 SKC 查询失败不会终止整个批次。
9. 点击“继续执行”只处理待执行和可重试任务。

## 14. MVP 交付范围

- XLSX 导入和任务预检。
- 本地任务状态和当前 SKC 站点查询缓存。
- 区域切换和批量资格查询。
- 可开启、已加速、无资格、无站点、无商品、价格超限跳过状态。
- 单个任务完整开启和 X/Y 填写。
- 按 SKC 分组的站点顺序批量队列、暂停、继续、结果导出。
- 自动价格确认、自动立即加速和提交后验证。
