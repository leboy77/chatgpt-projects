# Temu 批量指定规格流量加速器

这是一个本地 Chromium Manifest V3 扩展，用于按 Excel 任务批量开启 Temu 流量加速并填写超级流量加权申报价。

## 已实现规则

- 默认区域为欧区，支持全球、美国、欧区。
- 面板可填写指定规格 / 颜色组，默认 `Mixed Color2`，也支持“混合色”等中文本地化名称。
- 双表文件自动按 `SKC × 全部价格站点` 展开。
- 自动把“德国”“瑞典（无偏远）”等表内站点名规范化为平台使用的“德国站”“瑞典站”。
- 任务按 SKC 顺序串行，当前 SKC 的所有站点完成后才进入下一个 SKC。
- `Mixed Color2` 的 SKU 填写 Y，其他颜色组填写 X。
- 任一输入价格高于对应参考申报价时，整条站点任务标记为价格超限并跳过。
- “立即加速”按钮缺失时只跳过当前站点，不暂停后续队列。
- 用户点击一次“开始执行”后自动完成填写、确认、立即加速和结果回查。
- 提交前逐 SKU 回读并保存最终加速提价。
- 导出结果主表展示最终价格摘要，并提供按 SKU 展开的“最终价格明细”工作表。
- 大批量运行时只渲染当前附近的 240 行任务，并合并界面刷新与本地保存，避免每处理一个站点都重建 5,120 行 DOM。
- 查询超时自动重试；单个 SKC 仍失败时只结束该 SKC，队列继续。
- 再次点击时只继续待执行和失败重试任务，保留已完成、已跳过和已加速结果。
- 不自动修改平台的加速时长和自动续期默认值。
- 所有数据只保存在本地扩展中。

## 目录

- `manifest.json`：扩展入口。
- `content/`：Temu 页面自动化。
- `panel/`：注入页面的操作面板。
- `lib/`：Excel 解析和共享模型。
- `tests/`：不依赖真实店铺的自动测试。

## 安装

1. 打开 BitBrowser 或 Chrome 的扩展管理页。
2. 开启开发者模式。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录。

开发阶段不需要构建。修改文件后，在扩展管理页点击“重新加载”。

## 使用

1. 打开 Temu 商品流量页。
2. 点击页面右下角“批量加速器”。
3. 选择区域并导入 XLSX。
4. 核对任务列表后点击“开始执行”。

执行中不弹人工确认。价格超限任务会跳过并保留在结果中。
